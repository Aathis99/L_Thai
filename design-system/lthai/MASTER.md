> แหล่งอ้างอิงกลางสำหรับการออกแบบ UX/UI ของระบบ LThai (`apps/web`)
> อัปเดตจากข้อยุติ Q1–Q10 (26 พฤศจิกายน 2026) บน branch `ag_fortest`

## 1. แนวทางหลัก (Principles)

- **ถนอมสายตาสำหรับการทำงานต่อเนื่องทั้งวัน (Low-Glare Comfort):** เลี่ยงพื้นขาวจ้า `#FFFFFF` เต็มจอใน Light Mode และเลี่ยงดำสนิท `#000000` ใน Dark Mode เพื่อลดแสงสะท้อนและความล้าของดวงตา
- **สีมีหน้าที่ช่วยนำสายตา (Functional 60–30–10):** ไม่ใช้สีตกแต่งสุ่มสี่สุ่มห้า ทุกสีต้องสื่อลำดับความสำคัญหรือสถานะงานได้ทันที
- **อ่านง่ายแบบพอดี (Comfortable Thai Legibility):** คงฟอนต์เดิมของระบบ (`"Leelawadee UI", "Tahoma", sans-serif`) เพื่อความปลอดภัยในการ build Docker แบบออฟไลน์และความคุ้นตา แต่ขยับฐานขนาดตัวอักษรขึ้นเป็น `15px` และตัดข้อความจิ๋ว `<= 12px` ออกทั้งหมด
- **คงกระบวนการและข้อมูลเดิม 100%:** ปรับเฉพาะหน้าตา การจัดวาง ลำดับสายตา และไอคอน โดยไม่เปลี่ยน API, สิทธิ์การใช้งาน หรือ business logic
- **แยกสื่อสิ่งพิมพ์เด็ดขาด:** การปรับ token กลางต้องไม่กระทบสไตล์พิมพ์ A4 ใน `apps/web/src/components/qc-documents/print.css`

## 3. สเกลตัวหนังสือ (Comfortable Thai Type Scale)

- **Font Family:** `"Leelawadee UI", "Tahoma", sans-serif` (คงของเดิม รองรับออฟไลน์ 100%)
- **Base Body / ตาราง / Input / Button:** `15px`, `line-height: 1.6`
- **Minimum Text Size (หัวคอลัมน์, ป้ายสถานะ, ข้อความรอง):** `13.5px–14px` *(ห้ามใช้ขนาด ≤ 12px ในข้อมูลที่ต้องอ่าน)*
- **Section Heading (`h2`, `h3`):** `18px–20px`, `font-weight: 700`
- **Page Heading (`h1`):** `26px`, `line-height: 1.35`, `font-weight: 700`
- **KPI / ยอดตัวเลขสำคัญ:** `24px–26px`, `font-weight: 700`, `font-variant-numeric: tabular-nums`
- **ตัวเลขในตาราง (น้ำหนัก กก., จำนวนแผ่น, ฉบับ):** ใช้ `font-variant-numeric: tabular-nums` และจัดชิดขวา (`text-align: right`) เสมอ
- **Control Height:** ปุ่ม, ช่องกรอก, และ Dropdown สูงอย่างน้อย `40px` เพื่อความสบายในการคลิกและรองรับแท็บเล็ต

## 4. โครงสร้างกรอบหลัก (Shell & 3-Group Sidebar)

จัดเมนูแถบซ้ายใน `workspace.tsx` เป็น **3 กลุ่มตามสายงานจริง** (ซ่อนกลุ่มอัตโนมัติถ้าบัญชีไม่มีสิทธิ์เมนูในกลุ่มนั้น) และใช้ไอคอน SVG เส้นบางขนาด `18px` (`stroke-width: 1.75`, `aria-hidden="true"`):

1. **สายการผลิต:** รับดินและวัตถุดิบ → งานปั๊ม → งานชุบเคลือบ → งานเตา → ตรวจสอบคุณภาพ (QC) → สต็อก
2. **ข้อมูลหลัก:** หมวดหมู่
3. **บุคลากรและระบบ:** พนักงาน → ตำแหน่ง → บทบาท → บัญชีผู้ใช้ → ประวัติ

## 5. โมดูลต้นแบบแรก (Pilot: `รับดินและวัตถุดิบ`)

- **แถบสรุปด้านบน (Stock KPI Strip):** แสดงยอดคงเหลือรวมตามประเภทดินและจำนวนรายการร่าง/ยืนยันทันทีโดยไม่ต้องสลับแท็บ (คำนวณจากข้อมูล `state` เดิมของ `/raw-clay/state` ไม่ต้องแก้ API)
- **แถบแท็บ + ปุ่มโหลดล่าสุด:** แยกสถานะแท็บที่เลือกชัดเจนด้วยพื้นสี Selected + เส้นขอบนุ่ม
- **แถบค้นหาและช่วงวันที่:** จัดเป็นแถวเดียวกระชับบนจอ Desktop (`grid` ยืดหยุ่นอัตโนมัติบนจอแคบ) ลดความสูงที่กินพื้นที่ตาราง
- **ตารางเอกสาร:** ข้อมูลชัดเจน `15px`, ป้ายสถานะสี+จุด+ข้อความ (`ยืนยันแล้ว`, `ร่าง`, `ยกเลิกแล้ว`) + ป้ายฉบับ, ตัวเลขน้ำหนักชิดขวา `tabular-nums`, แถว hover นุ่มช่วยไล่สายตาแนวนอน
- **โมดัลรายละเอียด:** แยกกลุ่มปุ่มการกระทำตาม 4 ระดับสี (Primary ยืนยัน, Warning แก้ไข, Danger-soft ยกเลิก → ยืนยันยกเลิกด้วย Destructive ทึบ)

## 5.1 มาตรฐานหน้าต่างป๊อปอัป (Modal & Form Dialog Standard — Q1–Q3)

- **สัดส่วน 2 ขนาดมาตรฐาน:**
  - **ขนาดกลาง (`md` · `560px`):** สำหรับฟอร์มสั้น 1 คอลัมน์ (เบิกเข้าโม่, ปรับยอด, เพิ่มสีดิน/ตำแหน่ง, เปลี่ยนรหัสผ่าน, ยืนยันลบ)
  - **ขนาดกว้าง (`lg` · `800px`):** สำหรับฟอร์มหลายคอลัมน์หรือรายละเอียด+ประวัติ (เพิ่มใบรับดิน, เพิ่มผลคัด QC, ดูรายละเอียดและประวัติ, พนักงาน/ผู้ใช้/บทบาท, รายการสินค้า/ตั้งค่าผลิต)
- **โครงสร้าง 3 ชั้นตรึงหัว–ท้าย:** ทุก `<dialog>` ใช้ flex column สูงสุด `88dvh` (เว้นขอบจออย่างน้อย `24px` บน Desktop, `12px` บน Mobile):
  - `.modal-head` ตรึงด้านบน (`18px 24px`)
  - `.modal-body` เลื่อนเฉพาะส่วนเนื้อหาตรงกลาง (`20px 24px`)
  - `.modal-foot` ตรึงด้านล่าง (`14px 24px`) แสดงคำแนะนำรองซ้าย + ปุ่มกระทำขวา
- **การจัดผังฟอร์มยาว (รับดิน):** แบ่งกลุ่มชัดเจนเป็นการ์ดย่อย `.form-section`, วาง 2 คอลัมน์ (`.form-grid` / `.weigh-pair` ชั่งเข้าซ้าย–ชั่งออกขวา), วางช่อง `น้ำหนัก + หน่วย` แถวเดียวกัน (`.weight-row`) และจัด `วันที่ + ชม. + นาที` พร้อมปุ่มเวลาปัจจุบันใน `.clock-box` โดยเปิดแสดงทุกช่องครบเหมือนเดิม
