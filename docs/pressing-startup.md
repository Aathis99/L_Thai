# เปิดใช้งานงานปั๊มและลงยอดตั้งต้น

## เตรียมทะเบียนประเภทกระเบื้อง

1. ใช้ `ยอดปั๊มแผ่น-2569.xlsx` ชีต `พ.ย.69` เป็นรายการเสนอสำหรับทะเบียน คอลัมน์ E:G คือขนาด ชนิดดิน และดินสี ส่วน K คือแผ่นต่อไม้ และ M คือแผ่นต่อ ตร.ม. เทียบหัวคอลัมน์ใหม่เมื่อใช้ชีตเดือนอื่น
2. เทียบขนาดกว้าง × ยาว ประเภทดิน รายละเอียดดินสี และจำนวนแผ่นต่อไม้กับไม้จริงที่หน้างาน ตรวจรายการซ้ำและตกลงอัตราก่อนบันทึกเมื่อพบหลายอัตราในประเภทเดียวกัน ให้หน้างานยืนยันชื่อเรียก จำนวนวันพัก และปลายทางเบิก **งานสี** หรือ **เข้าเตา** เช่น บรีสที่ข้ามงานสี
3. ให้หน้างานเทียบ “ศิลาแลง” ในไฟล์สต็อกกับ “จ้อ” ในทะเบียนตามขนาดและดินจริง เมื่อยืนยันว่าเป็นประเภทเดียวกันให้ใช้ประเภทที่ตรงกันในทะเบียนและเก็บชื่อเรียกตามที่ตกลง พักรายการที่ยังเทียบไม่ได้ไว้ตรวจ
4. เปิด **งานปั๊ม → ทะเบียนประเภทกระเบื้อง → เพิ่มประเภทกระเบื้อง** แล้วบันทึกข้อมูลที่ยืนยันแล้ว กรอก **จำนวนแผ่นต่อ ตร.ม.** เมื่อยืนยันอัตราได้

## ตรวจนับ ณ วันตัดยอด

1. ตกลงวันและเวลาตัดยอดกับหน้างาน ตรวจปีในหัววันที่ Excel ให้ตรงกับรอบจริง กำหนดให้ยอดตั้งต้นครอบคลุมของที่เหลือ ณ เวลาตัดยอด และเริ่มลงรายการเคลื่อนไหวใหม่ในระบบหลังเวลานั้น หากมียอดปั๊มที่รับเข้าระบบแล้ว ให้กันออกจากยอดตั้งต้นเพื่อป้องกันการนับซ้ำ
2. เทียบ `สต็อกคงเหลือ.xlsx` กับยอดกองจริง ตัวอย่างชีต `พย69` ใช้หัวกลุ่ม A1:J4 และยอดปิด IQ1:IY4 ตรวจแต่ละกองว่ามีกี่แผ่น เป็นกระเบื้องประเภทใด อยู่ขั้นตอนไหน เหลือให้เบิกจากงานปั๊มจริงเท่าไร และมีส่วนที่ผูกกับออเดอร์ใด ตรวจขั้นตอนของยอดบรีสโดยเฉพาะ ใช้ `Sheet1` ที่หักออเดอร์ประกอบการตรวจยอดผูกออเดอร์ และใช้ผลตรวจนับยืนยันยอดกองจริง
3. ยืนยันวันครบกำหนดพักหรือให้หน้างานตรวจความพร้อมจริง พักรายการที่ยังระบุประเภท ขั้นตอน หรือข้อผูกพันกับออเดอร์ไม่ได้ และพักยอดที่ยืนยันแล้วว่ายังผูกออเดอร์ไว้จนตกลงวิธีลงรายการ เพราะยอดตั้งต้นเข้ายอดทั่วไปและไม่มีช่องผูกใบสั่งผลิต
4. เก็บไฟล์ Excel ต้นฉบับและไฟล์ตรวจนับหรือเตรียมข้อมูลที่มีข้อมูลจริงไว้นอก Git

## บันทึกยอดตั้งต้นที่ยืนยันแล้ว

1. กำหนด **รหัสอ้างอิงยอดตรวจนับ** (`source_key`) คงที่ให้แต่ละรายการที่ยืนยันแล้ว โดยอ้างอิงรอบตรวจนับและรหัสกองหรือรหัสรายการที่ตรวจย้อนกลับได้ เก็บรหัสคู่กับรายการต้นทาง และใช้รหัสเดิมเมื่อส่งรายการเดิมซ้ำ ระบบใช้รายการเดิมเมื่อข้อมูลตรงกัน และแจ้งว่ารหัสถูกใช้แล้วเมื่อข้อมูลต่างกัน หากพบยอดคลาดเคลื่อนให้ตรวจรายการเดิมกับผู้รับผิดชอบก่อนดำเนินการ การออกรหัสใหม่ให้ยอดเดิมจะเพิ่มสต็อกซ้ำ
2. เปิด **งานปั๊ม → สต็อกและเบิก → ลงยอดตั้งต้น** กรอกรหัส เลือก **ประเภทกระเบื้อง** แล้วระบุ **วันที่ตรวจยอดตั้งต้น** และ **จำนวนแผ่นตั้งต้น** ตามยอดที่ยืนยัน หน้าจอส่งข้อมูลไปที่ `POST /pressing/opening` เพื่อเพิ่มแหล่งสต็อก
3. กรอก **วันครบกำหนดพัก (ถ้าทราบ)** เมื่อมีวันที่ยืนยันแล้ว หากไม่ทราบวันและหน้างานตรวจว่าพร้อมแล้ว ให้เลือก **ตรวจยืนยันพร้อมเบิกแล้ว (กรณีไม่ทราบวันครบกำหนดพัก)** หากยังรอตรวจ ให้เว้นทั้งสองช่อง ยอดจะแสดง **รอยืนยันความพร้อม** และผู้เบิกใช้ **ยืนยันความพร้อมยอดตั้งต้น** ได้หลังตรวจสภาพจริง
4. หลัง **บันทึกยอดตั้งต้น** ให้เทียบ **คงเหลือ (แผ่น)** ปลายทางเบิก และสถานะพักของแต่ละแหล่งใน **สต็อกและเบิก** กับรายการตรวจนับก่อนเริ่มเบิกจริง

## กำหนดสิทธิ์และเริ่มงาน

ก่อนตั้งทะเบียนและลงยอด ให้ผู้ดูแลกำหนดสิทธิ์ในหน้าบทบาทตามหน้าที่จริง ทุกบทบาทที่ใช้เมนู **งานปั๊ม** ต้องมี **ดูข้อมูลงานปั๊ม** (`pressing.read`) ผู้ดูรายงานใช้สิทธิ์นี้ได้อย่างเดียว

| หน้าที่ | สิทธิ์เพิ่มเติม |
| --- | --- |
| ดูแลประเภท ใบสั่ง และยอดตั้งต้น | จัดการทะเบียนและใบสั่งผลิต (`pressing.manage`) |
| ธุรการบันทึกยอดตามผู้ปั๊ม | บันทึกยอดปั๊ม (`pressing.record`) |
| ผู้ตรวจความพร้อมและยืนยันเบิก | ยืนยันเบิกสต็อกงานปั๊ม (`pressing.issue`) |
| ผู้อนุมัติให้ใช้ส่วนเกินกับงานอื่น | ปล่อยยอดปั๊มส่วนเกิน (`pressing.release`) |
| ผู้บันทึกงานเผาและส่งผลคัด | ส่งผลคัดหลังเผา (`pressing.sort`) |
| ผู้แก้รายการปั๊ม ปรับยอด หรือย้อนเบิก | ปรับยอดงานปั๊ม (`pressing.correct`) การแก้ผลคัดต้องมี `pressing.sort` ด้วย |

1. เปิด **งานปั๊ม** ระบบจะแสดงหน้า **ใบสั่งผลิต** เลือก **เพิ่มใบสั่งผลิต** แยกหนึ่งประเภทต่อใบ ระบุเลขอ้างอิงเมื่อผลิตตามออเดอร์ลูกค้า
2. ใน **บันทึกยอด** เลือก **บันทึกยอดปั๊ม** แล้วเลือกใบสั่งผลิตที่ใช้งาน วันที่ปั๊มจริง ผู้ปั๊มที่ยังทำงานอยู่ จำนวนไม้เต็ม และแผ่นเศษ บันทึกแยกตามผู้ปั๊ม ระบบคำนวณจำนวนแผ่นและรับเข้าสต็อกพร้อมวันครบกำหนดพัก
3. ใน **สต็อกและเบิก** เลือก **เบิกสต็อก** ตรวจสภาพจริง เลือกประเภท ปลายทาง แหล่งสต็อก ส่วนสต็อก และจำนวนแผ่น หากใช้ยอดผูกใบสั่งให้เลือกใบสั่งเดิม หากแยกต้นทางจริงในกองรวมไม่ได้ให้เลือก **เบิกจากกองรวม** แล้วกด **ยืนยันการเบิก** ผู้มีสิทธิ์ใช้ **ปล่อยส่วนเกิน** เมื่ออนุมัติให้ยอดส่วนเกินจากใบสั่งใช้กับงานอื่น
4. ใน **ผลคัด** ใช้ **เพิ่มงานเผา** แล้วเลือก **บันทึกผลคัด** เมื่อคัดครบ ระบุประเภท วันที่คัดเสร็จ จำนวนแผ่นดีและเสีย และผู้ปั๊มเฉพาะเมื่อมีข้อมูลตามกลับได้ จากนั้นกด **ส่งผลคัด**

ถ้าเน็ตหลุดระหว่างบันทึกและระบบแจ้งว่ายังไม่ทราบผล ให้ใช้ **ลองส่งอีกครั้ง** ในหน้าต่างเดิมเมื่อปุ่มนี้ปรากฏ ถ้าปิดหน้าต่างหรือหมดเวลาล็อกอิน ให้เปิดรายการล่าสุดและตรวจประวัติว่าบันทึกสำเร็จแล้วหรือยังก่อนลงรายการซ้ำ
