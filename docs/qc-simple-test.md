# ลองงานเตาและ QC รูปแบบใหม่

> ประวัติชุดQAเดิม: ปัจจุบันย้ายรุ่นใหม่ขึ้นหลักและถอดQAแล้ว ให้ใช้ [คู่มือเริ่มระบบโล่งที่พอร์ต3001](clean-system-start.md) ข้อมูลตัวอย่างด้านล่างเก็บไว้ในbackupQAเท่านั้น

ใช้เฉพาะ **QA** ที่ http://qc.localhost:3160 บัญชี `qc-review` รหัสอยู่ใน `.qa/qc-documents/review-account.txt` ระบบหลัก3001ยังเป็นรุ่นเดิม

## ลองลง QC ด้วยตัวเอง — งานฝึก 120 แผ่น

1. เข้าเมนู **ตรวจสอบคุณภาพ(QC)**
2. ดูช่อง **งานออกเตาที่พร้อมเปิดใบ QC** เลือกออเดอร์ **QA-QC-PRACTICE-120** รอบ#27 แล้วกด **เปิดใบ QC**
3. ตรวจยอด **เข้า120 / ออก120 / ยืนยัน0 / ยังไม่คัด120** ยอดออกเติมอัตโนมัติ
4. กด **เพิ่มผลคัด** เลือกผู้คัด **QAQC001 · ผู้คัดตัวอย่าง สำหรับทดสอบ QC** ตั้งวันเวลาตรวจ **25 พ.ย. 2569 เวลา19:00** (เป็นเวลาของชุดตัวอย่างสำหรับทดสอบ)
5. กรอกครั้งแรกตามตาราง แล้วกด **บันทึกร่าง**:

| ช่อง | จำนวน |
| --- | ---: |
| A+ | 50 |
| ไม่สุก → เข้าเตาใหม่ | 3 |
| แต้ม → เข้าเตาใหม่ | 2 |
| หัก ในตารางอาการเสีย | 5 |

**ผลที่ควรเห็น:** ร่าง60 แต่ยืนยันยัง0 และยังไม่คัด120 ยอดเสียรวมเป็น5เอง

6. ตรวจรายการร่างแล้วกด **ยืนยันครั้งนี้** → ยืนยัน60 / ยังไม่คัด60
7. กด **เพิ่มผลคัด** อีกครั้ง ใช้ผู้คัดเดิมและเวลา19:30 กรอก **A+50 / ไม่สุก2 / แต้ม3 / หัก5** บันทึกร่างแล้วกดยืนยัน
8. ต้องได้ยอดสุดท้าย **A+100 / เสีย10 / ไม่สุก5 / แต้ม5 / ยังไม่คัด0** รวม120แผ่น
9. กด **สร้างฉบับทางการ** → **พิมพ์ / บันทึก PDF** เลือก A4 แนวตั้ง ตรวจหัวออเดอร์ ตารางเสียและช่องเซ็น

ถ้ายังไม่ยืนยันครบ ให้ใช้ **ดู / พิมพ์ร่าง** เอกสารต้องมีข้อความร่าง การกรอกร่างหรือพิมพ์เอกสารไม่เพิ่มสต็อก

### ลองการแจ้งเตือนและเวลา 24 ชั่วโมง

- ในเพิ่มผลคัด ใช้ช่อง **วันที่ / ชั่วโมง (00–23) / นาที (00–59)** เช่น19และ30คือ19:30 ไม่มีAM/PM
- งานฝึกรอบ#27เอาของลง18:00 ลองกรอก17:59วันที่เดียวกันแล้วบันทึก ต้องขึ้นalert **เวลาไม่สัมพันธ์กัน: เวลาคัดต้องไม่ก่อนเอาของลง** ฟอร์มและยอดที่กรอกยังอยู่ แก้เป็น19:00แล้วบันทึกได้
- หากจำนวนผิดเงื่อนไขหรือAPIปฏิเสธ ต้องแจ้งเหตุผล และไม่ปิดฟอร์มจนกว่าจะบันทึกสำเร็จ

## ลองดูตัวอย่างที่เสร็จแล้ว

เปิดใบ **QC-2569-000001** ออเดอร์ `QA-QC-OD-001/002` รวม240แผ่น จะเห็นผลแยกสองออเดอร์และฉบับแก้ไขครั้งที่1 เปิดฉบับเก่าเทียบได้โดยหมายเหตุเก่าไม่เปลี่ยน กด **พิมพ์ใบจดหน้างาน** เพื่อดูแบบกระดาษว่างสำหรับคนงาน

## ลองดูงานเตารูปแบบใหม่

เข้าเมนู **งานเตา** ใช้แท็บ **แผนและเตรียม → ภาพรวม → รอบเผาและไฟ** รอบฝึก#27 เตรียม/เผา/นำออก/เอาของลงเสร็จไว้ให้แล้ว เพื่อเริ่มทดลอง QC ได้ทันที การลองตั้งแต่ต้นให้ใช้ใบสั่งผลิตและของพร้อมจริงใน QA วางแผน → ยืนยันเตรียมลงเบอร์ → ยืนยันเบอร์พร้อม → เข้าเผา → ปิดไฟ → นำเบอร์ออก → เอาของลงเสร็จ แล้วจึงเปิดใบ QC

มีเพียงรูปแบบใหม่ในหน้าทำงานแล้ว ไม่มีปุ่มเปิดงานเตา/QC แบบเก่า ข้อมูลแบบเก่าในตารางเตา/QC ของ QAเป็น0 และลบรอบ#5พร้อมเอกสารที่ผูกกับรอบเก่านั้นแล้ว สำรองก่อนลบอยู่ `data/backups/qc-retirement-*` ตารางโครงสร้างที่ส่วนงานอื่นยังอ้างถึงคงไว้โดยไม่มีข้อมูลเก่า

ทั้งหมดเป็นข้อมูลฝึกใน QA ก่อนนำขึ้นหลักยังต้องตรวจรับและยืนยันข้อมูลที่จะเก็บตาม AGENTS.md
