# งานเตาและ QC ในระบบหลัก

เปิด http://127.0.0.1:3001 แล้วเลือก **งานเตา → งานปัจจุบัน** ใช้บัญชีโรงงานเดิมตามสิทธิ์ ผู้ใช้ยืนยันให้เริ่มงานเตารุ่นใหม่ว่างและไม่ย้ายชุดทดลอง QA

## ก่อนเข้าเผาครั้งแรก

1. ตรวจใบสั่งผลิตและยอดพร้อมจากชุดชุบหรือใบเบิกบรีส ข้อมูลต้นทางเดิมยังอยู่ครบ
2. ใน **ตั้งค่า** เลือกงานและบันทึกช่วงอุณหภูมิที่หน้างานยืนยันของดิน สีเมื่อมี และรูปแบบกระเบื้อง ช่วงดิน/สี/รูปแบบใช้ร่วมกับทะเบียนเดียวกัน งานที่ยังขาดเกณฑ์วางแผนได้ แต่เตรียมเข้าเผาไม่ได้
3. ยืนยัน **เกรดที่รับ** แยกเกรดที่ออเดอร์นั้นยอมรับ และเกรดที่โรงงานรับเข้าสต็อกได้ เกรดสต็อกใช้ร่วมกันทุกงาน ยังไม่กำหนดหมายถึงรอจัดสรร

## ทำงานตามรอบ

- **แผนและเตรียม**: วางแผนเป็นแผ่นหรือ ตร.ม. และยืนยันจำนวนเต็ม แผนยังไม่กันของ กด **ยืนยันเตรียมลงเบอร์** จึงกันยอดจากใบเบิก/ชุดชุบจริง แบ่ง ย้าย หรือยกเลิกก่อนเข้าเผาได้โดยคืนยอดที่กันไว้
- **ภาพรวม**: ยืนยันเบอร์พร้อมเข้า แล้วเข้าเผาพร้อมวันเวลาจริงและอุณหภูมิ เตาหนึ่งใช้ได้ครั้งละหนึ่งเบอร์
- **รอบเผาและไฟ**: บันทึกไฟด้วยมือทุกครึ่งชั่วโมงตามเวลาจริง พร้อมโคน/หมายเหตุ จากนั้นบันทึกปิดไฟ นำเบอร์ออก และเอาของลงเสร็จแยกเหตุการณ์ เบอร์ใช้ใหม่ได้หลังเอาของลง แม้ QC รอบเก่ายังไม่ครบ
- **QC**: คัดบางส่วนได้ ยอดที่เหลือยังเป็นรอคัด แยก A+, A-, B, เสีย, ไม่สุก และแต้ม ยอดอาการเสียหลักรวมต้องตรงกับยอดเสีย โดยแผ่นหนึ่งนับอาการหลักหนึ่งอย่าง
- **ซ่อม/เผาซ้ำ**: ยืนยันพร้อมบางส่วนได้ แล้ววางแผนกลับเข้าเตาโดยยังตามต้นทางเดิม ไม่เบิกดินใหม่และไม่เพิ่มยอดผลิตใหม่
- **จัดสรรออเดอร์/รับสต็อก**: เลือกเกรดและจำนวนเพื่อยืนยันปลายทาง ส่วนเกินออเดอร์รับเข้าสต็อกได้เมื่อกันยอดออเดอร์ครบแล้ว งานสั่งเก็บสต็อกใช้ปลายทางสต็อกโดยตรง

ยอดยืนยันรับเข้าจะแสดงที่ **สต็อก → สินค้าสำเร็จ** แยกเกรด ข้อมูลรับเข้าเดิมที่ไม่มีเกรดยังคงอยู่ในกลุ่ม **ยังไม่ระบุ (ข้อมูลเดิม)**

## งานสั่งเก็บสต็อก

ที่ **งานปั๊ม → ใบสั่งผลิต → เพิ่มใบสั่งผลิต** เลือก **ผลิตเก็บสต็อก** ระบุประเภท สีเมื่อมี และยอดเป้าหมาย แล้วบันทึกปั๊ม/เบิก/ชุบหรือบรีสตามเส้นทางเดิม งานเตาจะแสดงรหัส OS และงานซ่อมเป็น OSP ไม่ต้องสร้างยอดลูกค้าสมมติ

## งานเดิมและการแก้ยอด

- เลือก **งานเดิมก่อนเปิดขั้นตอนใหม่** เพื่อทำงานค้าง/คัด QC และตรวจประวัติเดิม รอบ/ผลคัด/สต็อกเดิมไม่ถูกลบ งานเข้าเผาใหม่ใช้แผนและเตรียมลงเบอร์ในงานปัจจุบัน
- แก้ยอดของงานปัจจุบันจาก **รอบเผาและไฟ → แก้ยอด** พร้อมรายการที่เกี่ยวข้อง ระบบจะบันทึกเมื่อยอดเข้าเผา QC ซ่อม และจัดสรรสอดคล้องกันทั้งหมด รายการรับสต็อกจากงานเตาแก้ที่จุดนี้ด้วย
- ถ้าฟอร์มแจ้งว่าข้อมูลหรือทะเบียนเปลี่ยน ระบบจะไม่บันทึกทับ ให้ตรวจข้อมูลล่าสุดแล้วเปิดฟอร์มใหม่ ข้อผิดพลาดจากการกรอกทั่วไปยังเก็บฟอร์มไว้ให้แก้
- **ประวัติ** แสดงผู้บันทึกและค่าก่อน–หลัง 100 รายการล่าสุด หลักฐานทั้งหมดเก็บในฐานข้อมูล

บันทึกไฟยังเป็นการลงด้วยมือ ไม่มีระบบอ่านอุณหภูมิอัตโนมัติ และยังไม่รวมต้นทุนหรือนำเข้าประวัติจากสมุดเก่าอัตโนมัติ
