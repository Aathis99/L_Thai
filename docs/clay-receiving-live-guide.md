# รับดินและวัตถุดิบ — ระบบหลัก

เปิดใช้งานจริง 26 พฤศจิกายน 2026 ที่ http://127.0.0.1:3001 ใช้บัญชีเดิมของโรงงาน แล้วเข้าเมนู **รับดินและวัตถุดิบ**

## ยอดเริ่มต้นที่อนุมัติ

ผู้ใช้ยืนยันให้นำยอดดินขาวหกรายการจาก Markdown มาใช้จริง รวม **66,983 กิโลกรัม หรือ 66.983 ตัน** ตัดรายการทรายออก ตั้งยอดด้วยรายการปรับยอด **RA-2569-000001**

เปิด **ปรับยอดและประวัติ** เพื่อดูรายการนี้ หมายเหตุเก็บชื่อดิน ผู้ขาย เลขบิล วันที่ และจำนวนตามแถวต้นทาง พร้อมชื่อไฟล์และ SHA256 ไม่สร้างเวลาชั่ง ทะเบียนรถ ผู้รับหรือภาพบิลที่ไม่มีในเอกสาร ยอดนี้เป็นยอดเริ่มต้นตามคำสั่งผู้ใช้ ไม่ใช่ใบรับรถเที่ยวใหม่

## งานประจำวัน

1. **รับเข้า:** กรอกบิล ชื่อดินและประเภทดิน วันเวลาชั่งผู้ขาย/รับที่โรงงาน ผู้รับจริง และน้ำหนัก เลือกกิโลกรัมหรือตันได้ บันทึกร่างก่อน แล้วแนบรูป1–3รูปและตรวจข้อมูลก่อนยืนยันเพิ่มยอด
2. **สต็อกวัตถุดิบ:** ดูยอดรวมตามประเภทดิน เช่น ดินขาว ชื่อการค้าอยู่ในประวัติใบรับ ไม่แยกกองตามชื่อ
3. **เบิกเข้าโม่:** ระบุประเภทดิน จำนวน วันเวลาและผู้เบิก ยืนยันแล้วลดยอด ไม่สร้างจำนวนแผ่นปั๊มโดยอัตโนมัติ
4. **ปรับยอดและประวัติ:** เมื่อทราบยอดตรวจนับใหม่ ให้ปรับด้วยเหตุผลและผู้ตรวจนับ แยกจากการแก้บิลรับที่กรอกผิด การแก้บิลก่อนวันตรวจนับคงค่าตรวจนับไว้และคำนวณส่วนต่างใหม่พร้อมประวัติ

เวลาชั่งเข้าเป็นก่อนใส่ดินที่ผู้ขาย ชั่งออกเป็นรถพร้อมดินก่อนออกส่ง แยกจากเวลารับที่โรงงานและเวลาบัญชีบันทึก ข้อมูลชั่งที่เอกสารไม่มีเว้นพร้อมหมายเหตุได้ น้ำหนักสุทธิจำเป็นเสมอ และเมื่อมีน้ำหนักสองฝั่งครบต้องตรงกับผลต่าง
