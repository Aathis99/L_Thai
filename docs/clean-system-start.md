# เริ่มทดสอบระบบโล่ง ตั้งแต่งานปั๊มถึง QC

ใช้ระบบหลักที่ http://localhost:3001 เข้าด้วยบัญชีเดิม ระบบ QA3160ถูกถอดออกแล้ว

ผู้ใช้ยืนยัน25พฤศจิกายน2569ให้นำรุ่นใหม่ขึ้นหลัก และเริ่มรายการงาน/สต็อกใหม่ทั้งหมด เก็บพนักงาน หมวดหมู่ บัญชีผู้ใช้ ตำแหน่ง สิทธิ์ และค่าทะเบียน/ช่วงอุณหภูมิเดิม ไม่ย้ายข้อมูลตัวอย่าง QA มาหลัก

## เริ่มหนึ่งออเดอร์

1. **หมวดหมู่** — ตรวจสินค้า แบบดินปั๊ม ประเภทดิน สีดิน/สีเคลือบ จำนวนแผ่นต่อไม้ และระยะพัก ให้ตรงสินค้าที่จะลอง
2. **งานปั๊ม** — สร้างใบสั่งผลิต ใส่เลขอ้างอิงที่จำได้ เช่น `TEST-001` ลงยอดปั๊มและผู้ทำงานจริง รอให้ครบระยะพักแล้วจึงยืนยันยอดพร้อมเบิก
3. **เบิกของ** — เบิกจากยอดปั๊มของใบสั่งนั้น ตามเส้นทางสินค้าที่ตั้งไว้ หากต้องชุบให้เบิกไปงานชุบ; บรีสที่กำหนดเข้าตรงให้ส่งไปเตา
4. **งานชุบเคลือบ** — ลงผู้ทำงาน ยอดชุบดี และเสีย ยอดดีเป็นต้นทางสำหรับงานเตา
5. **งานเตา** — ตรวจช่วงอุณหภูมิดิน สี และรูปแบบ ตั้งเกรดที่ออเดอร์รับเป็นA+ วางแผน → ยืนยันเตรียมลงเบอร์ → ยืนยันเบอร์พร้อม → เข้าเผา → บันทึกไฟ → ปิดไฟ → นำเบอร์ออก → เอาของลงเสร็จ
6. **ตรวจสอบคุณภาพ(QC)** — เปิดใบจากงานที่เอาของลงแล้ว พิมพ์ใบจดหน้างานได้ จากนั้นธุรการกดเพิ่มผลคัด เลือกวันที่/ชั่วโมง00–23/นาที00–59 ผู้คัด และยอดของแต่ละออเดอร์ บันทึกร่างเพื่อตรวจ แล้วจึงยืนยัน
7. คัดครบและข้อมูลครบแล้วกด **สร้างฉบับทางการ → พิมพ์ / บันทึก PDF** ตรวจหัวออเดอร์ ตารางเสีย และช่องเซ็น
8. ใช้ **จัดสรร / ซ่อม** เพื่อจัดสรรA+ให้ออเดอร์หรือรับสต็อกตามสิทธิ์ ส่วนไม่สุก/แต้มส่งเผาซ้ำ ถ้าสินค้าต้องติดตาข่ายให้ทำขั้นตอนตาข่ายต่อ

ใช้วันเวลาตามการทำงานจริงเรียงตามเหตุการณ์ ไม่คัดก่อนเอาของลงและไม่เบิกก่อนของพร้อม หากยังไม่มีของพร้อมให้ตรวจระยะพักและยอดต้นทางก่อน

## สิ่งที่ต้องเห็น

- เริ่มต้นไม่มีใบสั่งผลิต รายการปั๊ม ยอดสต็อก งานชุบ รอบเผา หรือใบQCเก่า
- ร่างQCยังไม่ลด “ยังไม่คัด” จนกดยืนยัน ผลA+/เสีย/ไม่สุก/แต้มรวมต้องเท่ากับยอดที่คัด และคัดสะสมไม่เกินยอดเข้า ยอดออกอ้างยอดเข้าอัตโนมัติ
- ตัวอย่างถ้ามีของเข้าเตา120แผ่น: ครั้งแรกA+50/เสีย5/ไม่สุก3/แต้ม2 รวม60 ยืนยันแล้วเหลือรอ60; ครั้งที่สองA+50/เสีย5/ไม่สุก2/แต้ม3 ต้องจบที่A+100/เสีย10/ไม่สุก5/แต้ม5 รอ0
- เวลาคัดก่อนเอาของลงต้องขึ้นalert “เวลาไม่สัมพันธ์กัน: เวลาคัดต้องไม่ก่อนเอาของลง” จำนวนเกินต้องแจ้งเหตุผลและเก็บฟอร์มไว้ให้แก้
- การพิมพ์ไม่เพิ่มสต็อก และร่างระหว่างคัดต้องแสดงข้อความร่าง

การล้างครั้งนี้คงลำดับรหัสไว้เพื่อไม่ให้รหัสใหม่ซ้ำประวัติเก่า จึงไม่จำเป็นต้องเริ่มรหัสงานจาก1 ประวัติบริหาร/ตรวจสอบเดิมยังเก็บไว้พร้อมบันทึกการล้าง
