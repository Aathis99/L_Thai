# ตรวจรับอุณหภูมิอ้างอิงในชาร์ตสี

สถานะ23พฤศจิกายน2026: เปิด QA แล้ว ยังไม่ได้นำขึ้นระบบจริง

- เข้า http://localhost:3160 ใช้localhostเพื่อแยกcookieจากหลัก127.0.0.1:3001
- บัญชี QA อยู่ในไฟล์ส่วนตัว `.qa/color-reference-temperature/login.json` ไม่อยู่ในGit
- ไป หมวดหมู่ → ชาร์ตสี จะเห็นอุณหภูมิอ้างอิงใต้ชื่อ เปิดรายละเอียดแล้วกด “แก้อุณหภูมิอ้างอิง” ใส่ค่าจริงหรือเว้นว่างเพื่อล้าง
- ผู้ดูชาร์ตสีอ่านค่าได้ ผู้ตั้งอุณหภูมิที่อ่านชาร์ตสีได้แก้ค่าได้แม้ไม่มีสิทธิ์แก้ชื่อ/รูป ผู้มีเฉพาะสิทธิ์แก้สีเปลี่ยนอุณหภูมิไม่ได้
- สี `QA-COLOR-REF ไม่ย้ายขึ้นหลัก` เป็นตัวอย่างเฉพาะQA ทดลอง1234.5แล้วล้างเรียบร้อย ไม่ใช่ข้อมูลโรงงาน ไม่ย้ายตัวอย่างหรือบัญชีQAขึ้นหลัก
- ค่าใหม่ใช้แสดงข้อมูลเท่านั้น ช่วงต่ำสุด/สูงสุด กติกาจัดเข้าเตา สีดินและบันทึกโคนยังคงเดิม

## ผลตรวจ

สำรองหลักใหม่และกู้เป็นฐาน/role `lthai_color_reference_qa` ตรวจtargetก่อนเขียน migrationสองรอบรักษาข้อมูลเดิมครบ45ตาราง ทดสอบlegacy14/API120/เว็บ47 รวม181ผ่าน0ล้ม9ข้าม (5ต้องมีExcelส่วนตัว,4 importer integrationผูกQAเก่าที่ปิดแล้ว) TypeScriptและDocker QA API/web buildผ่าน

ตรวจbrowserบันทึกทศนิยม/ล้างค่า/ค่าไม่ระบุในรายการและรายละเอียด จอ390pxเนื้อหากว้าง375ไม่ล้น ตรวจสิทธิ์แยกและช่วงเผาเดิมด้วยAPI tests ผู้รีวิวอิสระพบเรื่องโหลดค่าล่าสุดก่อนเริ่มแก้และโหลดรายการหลังบันทึกผิดพลาด แก้แล้ว ตรวจbuild/typecheckผ่าน

ข้อจำกัดหลักฐาน: ยังไม่ได้จำลองเครือข่ายขาดหลังPUTสำเร็จและการลบสีจากอีกแท็บในbrowser การรักษาค่าที่บันทึก/โหลดเฉพาะGETและการปิดสีที่หายใช้pattern refreshเดิมที่reviewโค้ดแล้ว ไม่ถือว่าสถานการณ์เหล่านี้ผ่านbrowser test
