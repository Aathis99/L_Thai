# บันทึกการทำงานสลับเครื่อง

วันที่: 2026-11-10
สถานะ: ผู้ใช้ยืนยันข้อกำหนดครบแล้ว รวมถึงใช้ Docker เป็นฐานตั้งต้น; พัฒนาตามแบบใน cross-machine-workflow-design.md

## ข้อกำหนดที่ผู้ใช้ยืนยัน

- เป้าหมายคือเปิดอีกเครื่องแล้วทำงานต่อได้โดยไม่ต้องอธิบายบริบทใหม่
- ทั้งเครื่องที่ทำงานและเครื่องที่บ้านเป็นเครื่องส่วนตัว สามารถนำข้อมูลโปรเจกต์ออกได้ทั้งหมด
- ใช้งานทีละเครื่อง หยุดเครื่องหนึ่งก่อนเริ่มอีกเครื่อง
- ยอมรับขั้นตอนส่งงานและรับงานก่อนเปลี่ยนเครื่อง โดยใช้ Git สำหรับโค้ดและเอกสาร
- ข้อมูลในแอปและไฟล์ต้นทางต้องตามไปด้วย ไม่ใช่เฉพาะโค้ด
- นำ skills และกติกา AI ที่จำเป็นไปใช้บนอีกเครื่องด้วย
- เลือก OneDrive ส่วนตัวเป็นช่องทางส่งชุดข้อมูลที่ไม่อยู่ใน Git
- เครื่องที่บ้านใช้ Windows และ Codex และมี Docker/PostgreSQL เช่นเดียวกับเครื่องที่ทำงาน
- เลือกใช้ Docker เป็นสภาพแวดล้อมหลักทั้งสองเครื่อง
- ตอนรับงานให้นำข้อมูลรอบส่งงานมาแทนฐานปลายทาง โดยสำรองฐานปลายทางก่อนทุกครั้ง และหยุดตรวจสอบหากมีงานที่ยังไม่ได้ส่ง
- ยังไม่เลือกฐานเริ่มต้น ผู้ใช้อนุญาตให้เปรียบเทียบ native และ Docker แบบอ่านอย่างเดียวก่อน

## ข้อเท็จจริงจากการตรวจโปรเจกต์

- มี Git remote บน GitHub แล้ว
- มี README, GLOSSARY, ADR และเอกสารแผนงานที่อยู่ใน Git
- ยังไม่พบ AGENTS.md หรือไฟล์สรุปสถานะล่าสุดสำหรับรับช่วงงานในโปรเจกต์
- Git เว้น data/, .env, .tools/ และไฟล์ Excel จึงไม่ส่งส่วนเหล่านี้ไปด้วย
- มีคำสั่ง db:backup สำหรับสำรอง PostgreSQL อยู่แล้ว
- คำสั่ง db:backup เดิมสำรองเฉพาะ native พอร์ต 5433 ไม่ใช่ Docker พอร์ต 5434
- เอกสารอธิบายทั้ง PostgreSQL แบบ native และ Docker ซึ่งมีฐานข้อมูลแยกกัน
- ตรวจพบ Docker stack กำลังทำงาน (เว็บพอร์ต 3001, ฐานข้อมูลพอร์ต 5434) และ native PostgreSQL พอร์ต 5433 ทำงานพร้อมกัน แต่ยังสรุปไม่ได้ว่าฐานใดมีข้อมูลล่าสุด
- พบโฟลเดอร์ OneDrive ในเครื่องที่ทำงานแล้ว; ยังไม่ได้ตรวจเครื่องที่บ้าน
- ระหว่างตรวจพบ globals.css ที่ยังไม่ได้ commit; สถานะนี้อาจเปลี่ยนได้ ต้องตรวจใหม่ก่อนส่งงาน

## เรื่องที่ยังต้องตกลงหรือตรวจเพิ่มเติม

- ทดสอบรับงานจริงบนเครื่องที่บ้านหลัง commit/push และส่งชุดงานผ่าน OneDrive
- วิธีเตรียมเครื่องที่บ้าน
- วิธีตรวจว่ารับโค้ด บริบท และข้อมูลจากรอบงานเดียวกันครบแล้ว
- วิธีสำรองข้อมูลปลายทางก่อนนำข้อมูลจากอีกเครื่องเข้ามา

เอกสารนี้บันทึกข้อกำหนด ไม่ใช่หลักฐานว่ามีระบบซิงก์หรือทดสอบการย้ายเครื่องสำเร็จแล้ว
