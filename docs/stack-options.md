# ทางเลือก stack สำหรับโรงงาน

สถานะ: ผู้ใช้เลือก Next.js + Express API + PostgreSQL แล้ว ดู ADR 0001 สำหรับข้อสรุปที่ใช้จริง

## ความต้องการที่ยืนยันแล้ว

ใช้หลายคนผ่านมือถือ/คอมพิวเตอร์ในโรงงาน ชอบ React/Next.js/TypeScript เน้นดูแลง่ายและขยายงานออเดอร์ การเบิก และงานผลิตต่อได้

## ข้อเสนอหลัก

Next.js App Router + React + TypeScript + PostgreSQL เป็นแอปเดียว แยกโมดูลพนักงาน การเข้าถึง ออเดอร์ และการผลิตใน source โดยแต่ละโมดูลมี service ที่รับผิดชอบกติกาธุรกิจของตัวเอง ใช้ฐานข้อมูลกลางและ transaction ในการเบิก/หักยอดเมื่อมีข้อมูลกติกาจริง

หน้าจอและ API อยู่โปรเจกต์เดียวจึงมีชิ้นส่วนที่ต้องดูแลน้อยกว่าแยก Next.js กับ NestJS ตั้งแต่แรก ยังไม่ต้องเพิ่ม microservices, Redis หรือ queue จนมีงานที่ต้องใช้จริง

## ทางเลือก

| ทางเลือก | ข้อดีต่อโปรเจกต์นี้ | สิ่งที่ต้องแลก |
|---|---|---|
| Next.js + PostgreSQL แอปเดียว | TypeScript ทั้งหน้าจอและฝั่งเซิร์ฟเวอร์ ดูแลและนำขึ้นเครื่องง่าย | ต้องจัดโครงโมดูลและ service ให้ชัด |
| Next.js + NestJS + PostgreSQL | เหมาะเมื่อมีหลาย client หรือทีม backend แยก | ต้องดูแลสองแอปและขอบเขต authentication/API เพิ่ม |
| โครงเดิม Node native + SQLite | เปิดใช้งานและสำรองง่าย ไม่ต้องมี database server | ยังไม่มี React/TypeScript และโครง framework ที่ผู้ใช้ต้องการ |

ข้อเสนอการใช้ PostgreSQL เป็นวิจารณญาณของผู้พัฒนาเพื่อรองรับฐานข้อมูลกลางและการเขียนพร้อมกันในอนาคต จำนวนพนักงาน 36 คนเพียงอย่างเดียวไม่ได้ทำให้ SQLite ใช้งานไม่ได้

## สิ่งที่ต้องรักษาระหว่างย้าย

- ทะเบียนพนักงาน ตำแหน่ง บัญชี บทบาท ประวัติ และรหัสรายการที่อ้างอิงกัน
- รหัสผ่าน scrypt เดิม ไม่บังคับเปลี่ยนรหัสผ่านเพราะเปลี่ยน stack
- ตรวจสิทธิ์ที่เซิร์ฟเวอร์ทุกครั้ง และกันปิดผู้ดูแลคนสุดท้าย
- สำรอง SQLite ก่อนย้าย ทดลองย้ายและเทียบจำนวน/ความสัมพันธ์ก่อนสลับระบบจริง
- ไม่สร้างบัญชี login อัตโนมัติให้พนักงานจาก Excel

## คำตอบที่รอ

- เลือกแอปเดียวหรือ API แยก
- เครื่องเซิร์ฟเวอร์ในโรงงานหรือบนอินเทอร์เน็ต และความต้องการเมื่ออินเทอร์เน็ตล่ม
- รหัสพนักงานชั่วคราวและขอบเขตข้อมูลประวัติที่จะนำเข้ารอบนี้

## ข้อสรุปสุดท้าย

เลือก Next.js/React/TypeScript + Node.js/Express + PostgreSQL แยกหน้าบ้านและ API ตามที่ผู้ใช้ระบุ ใช้เครื่องในโรงงานและไม่พึ่งอินเทอร์เน็ตระหว่างงานปกติ นำเข้าเฉพาะชื่อกับโทรศัพท์และใช้รหัสชั่วคราว EMP69-001 ถึง EMP69-036
