# หารือแยกสต็อกวัตถุดิบดินตามผู้ขาย

เริ่ม 26 พฤศจิกายน 2026 ใช้ grill-with-docs ต่อจากโมดูลรับดินที่เปิดใช้จริงแล้ว เป้าหมายคือแยกยอดตามประเภทดินและบริษัท พร้อมหน้าจอเข้าใจง่าย

## ยืนยันแล้ว

- **Q1:** บริษัทหมายถึงผู้ขายวัตถุดิบดิน ไม่ใช่บริษัทในเครือที่เป็นเจ้าของดิน
- **Q2:** แยกยอดตามประเภทดินเดิม + ผู้ขาย ชื่อการค้ายังคงเป็นรายละเอียดของใบรับ ไม่แยกคงเหลือตามชื่อการค้า
- **Q3:** หน้างานแยกกองตามผู้ขายและประเภทดิน ซื้อจากสามแหล่ง ตัวอย่างผู้ขาย A มีดินขาว/ศิลาแลง/ดินแดงแยกล็อกหลังเครื่องโม่ ถัดลงมาเป็นดินโม่แล้ว ผู้ขาย B และ C จัดเก็บรูปแบบเดียวกันในโซนอื่นของโรงงาน จึงระบุผู้ขายจากกองที่หยิบได้ ยังไม่ได้ตกลงให้ระบบจัดการทะเบียนตำแหน่งจัดเก็บหรือสต็อกดินโม่แล้ว
- **Q4:** ต้องการรายชื่อผู้ขายที่เพิ่ม/ลบได้ และเลือกจาก Dropdown ผู้ใช้ยกตัวอย่างชื่อคล้ายกัน “บริษัทA” กับ “บรษัทA” ต้องตกลงวิธีป้องกันหรือจัดการชื่อซ้ำ รวมถึงความหมายของการลบเมื่อมีประวัติใช้งานแล้ว
- **Q5:** รอบนี้ทำเฉพาะรับดินก่อนโม่ → คงเหลือแยกประเภทดินและผู้ขาย → เบิกเข้าโม่ การเบิกลดจากกองที่เลือก ยังไม่รวมสต็อกดินโม่แล้วหรือคำนวณผลผลิตหลังโม่
- **Q6:** ผู้ขายที่ยังไม่เคยใช้งานลบได้ ผู้ขายที่เคยมีรายการให้ปิดใช้งานแทน ไม่แสดงเป็นตัวเลือกทำรายการใหม่ แต่รักษาบิลและประวัติเดิม
- **Q7:** ไม่ให้เพิ่มชื่อซ้ำตรงกัน ชื่อคล้ายกันให้เตือนและแสดงชื่อเดิมเพื่อตรวจ คนยืนยันว่าเป็นผู้ขายเดียวกันก่อนรวมรายชื่อที่สร้างซ้ำ โดยผู้ดูแลเป็นผู้ยืนยันและรักษาบิล/ประวัติทั้งหมด ไม่รวมอัตโนมัติจากความคล้ายของชื่อ
- **Q8:** เลือกหน้าหลักแบบแยกตามผู้ขาย เห็นดินแต่ละประเภทของผู้ขายนั้นพร้อมกันและกดเบิกจากกองได้เลย
- **Q9:** หนึ่งรายการเบิกต่อหนึ่งประเภทดินและผู้ขาย ถ้าโม่ครั้งเดียวใช้หลายกอง ให้บันทึกเบิกแยกรายการตามกอง
- **Q10:** ผู้มีสิทธิ์รับดินเพิ่มและแก้ชื่อผู้ขายได้ ผู้ดูแลระบบเป็นผู้ปิดใช้งาน ลบ และรวมรายชื่อซ้ำ
- **Q11:** แบ่งยอดเริ่มต้นดินขาว 66,983 กก. ตามตารางผู้ขายสามรายที่ตรวจจากหกแถวต้นทางและแสดงในแชต ยอดรวมก่อน/หลังเท่ากัน รักษาที่มา ไม่สร้างรับเข้าซ้ำ ดินแดง/ศิลาแลงลงยอดตามข้อมูลจริงภายหลัง ไม่เติมยอดสมมติ
- **Q12:** เติมรายละเอียด Q6: ใช้สถานะ “หยุดรับเข้า” ซ่อนผู้ขายจากตัวเลือกใบรับใหม่ แต่ยังแสดงกองเดิมและให้เบิก/ปรับยอดตามสิทธิ์ได้ โดยรักษาประวัติทั้งหมด
- บันทึกข้อเปลี่ยนจากการรวมยอดเดิมไว้ใน [ADR 0010](adr/0010-raw-clay-stock-by-type-and-supplier.md) และปรับคำศัพท์แล้ว
- ผู้ใช้ขอดูหน้าจอจำลองในแชตเพื่อเปรียบเทียบการจัดกลุ่มตามผู้ขายกับตามประเภทดิน เป็นแบบทดลองเพื่อเลือกแนวทาง ยังไม่ใช่หน้าจอที่อนุมัติพัฒนา ตัวเลขในแบบเป็นข้อมูลสมมติ

## แบบจำลองที่เสนอให้เลือก

- **แยกตามผู้ขาย — ผู้ใช้เลือก:** เห็นแต่ละผู้ขายพร้อมดินทุกประเภทในกลุ่มเดียวกัน เหมาะกับการหากองตามโซนหน้างาน
- **แยกตามประเภทดิน — ทางเลือกที่ไม่ได้เลือกเป็นหน้าหลัก:** เลือกประเภทดินก่อน แล้วเห็นยอดของทุกผู้ขาย เหมาะกับการเทียบยอดดินประเภทเดียวกันข้ามผู้ขาย ยังไม่ได้ตกลงให้พัฒนาเป็นมุมมองเพิ่มเติม
- ทั้งสองแบบกดเบิกจากยอดของกองนั้นเพื่อกรอกประเภทดินและผู้ขายให้ล่วงหน้า แสดงคงเหลือก่อน/หลังเบิก แบบจำลองทดสอบเฉพาะการเลือกกอง น้ำหนัก และชื่อผู้ขาย ไม่ใช่แบบฟอร์มรับ/เบิกฉบับเต็มที่ใช้จริง
- ผู้ใช้ทดลองปรับหน่วยในแบบจำลองเป็นกิโลกรัม บันทึกเป็นความเห็นประกอบแบบ ยังไม่ได้ยกเลิกตัวเลือกกิโลกรัม/ตันของระบบเดิม

## ข้อเท็จจริงของระบบปัจจุบัน

- โค้ดแยกยอดด้วยประเภทดินและสีดิน ผู้ขายในใบรับเป็นข้อความ ไม่มีทะเบียนผู้ขายหรือรหัสผู้ขายที่ใช้อ้างอิงร่วมกัน
- ใบเบิกและรายการปรับยอดยังไม่มีผู้ขายเป็นมิติของยอดคงเหลือ
- หน้าจอเดิมมีสี่แท็บ รับดิน / สต็อกวัตถุดิบ / เบิกเข้าโม่ / ปรับยอดและประวัติ
- ยอดเริ่มต้นดินขาว 66,983 กก. อยู่ในรายการปรับยอด RA-2569-000001 โดยอ้างหกแถวต้นทางในหมายเหตุ ไม่ใช่ใบรับแยกผู้ขาย ต้องจัดสรรโดยรักษายอดรวมและประวัติ ห้ามสร้างรับเข้าเพิ่มซ้ำยอดเดิม
- ตรวจต้นทางและฐานหลักใหม่แบบอ่านอย่างเดียว 26 พฤศจิกายน 2026: SHA256 ของ Markdown ตรงกับหลักฐานเดิม หกแถวแยกได้เป็นผู้ขายสามราย รวม 66,983 กก. ไม่มีชื่อสะกดต่างกันในหกแถว ชื่อจริงและยอดรายผู้ขายเป็นข้อมูลส่วนตัว จึงแสดงตารางให้ผู้ใช้ตรวจในแชต ไม่คัดลอกลง Git
- ตรวจ `current_database()=lthai` ก่อนอ่าน ฐานหลักขณะตรวจมีรายการเดียวคือปรับยอดดินขาว RA-2569-000001 สถานะยืนยัน ไม่มีผู้ขาย ไม่มีใบรับหรือใบเบิก ต้องตรวจรายการใหม่อีกครั้งก่อน cutover เพื่อรักษาการเปลี่ยนแปลงหลังการหารือนี้

## แบบเต็มและข้อกำหนดต่อผู้พัฒนา

- ผู้ใช้ตอบครบ Q1–Q12 แล้ว รวบรวมใน [แบบเต็ม](superpowers/specs/2026-11-26-clay-supplier-stock-design.md) เพื่อให้ตรวจยืนยันภาพรวมก่อนวางแผนพัฒนา การยืนยันคำถามรายข้อยังไม่ใช่การอนุมัตินำขึ้นหลัก
- ข้อกำหนดต่อผู้พัฒนา: เมื่อรวมผู้ขาย ต้องคงยอดคงเหลือรวมก่อน/หลังและหลักฐานตรวจนับเดิม ห้ามนำจุดตรวจนับต่างเวลามาบวกรวมเหมือนเป็นการตรวจนับครั้งเดียว หรือเปลี่ยนยอดโดยไม่มีรายการ/ประวัติ ต้องพิสูจน์กติกานี้ในแบบเต็มและ QA
- สรุปแบบรับ–ดูยอด–เบิก และการส่งต่อเข้าโม่ โดยใช้ประเภทดิน/สีดินและพนักงานเดิม ทะเบียนผู้ขายเป็นข้อมูลหลักร่วมของโมดูลรับดิน ผู้มีสิทธิ์ตาม Q10 ดูแลข้อมูลต้นทาง

สถานะ: ตอบครบ Q1–Q12 แบบเต็มผ่านผู้ตรวจอิสระในมุมผู้ที่จะวางแผนแล้ว ไม่มีคำถามสำคัญค้าง รอผู้ใช้ยืนยันแบบรวมและข้อเลือกเติมก่อนวางแผนพัฒนา QA ยังไม่อนุมัติพัฒนาหรือนำขึ้นหลัก ไม่มีการเปลี่ยนโค้ดหรือฐานข้อมูลจากการหารือนี้
