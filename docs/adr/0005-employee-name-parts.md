# เก็บชื่อพนักงานแยกส่วนโดยไม่เก็บชื่อรวมซ้ำ

ผู้ใช้เลือกเก็บคำนำหน้า ชื่อ และนามสกุลใน `prefix`, `first_name`, `last_name` และเลิกเก็บ `employees.name` เพื่อให้สามส่วนเป็นข้อมูลหลักชุดเดียว แทนทางเลือกที่เก็บชื่อรวมและต้องคอยปรับให้ตรงกัน แม้ต้องเปลี่ยน API ตัวนำเข้าและส่วนแสดงผลพร้อมกัน ชื่อหลายคำต้องอาศัยข้อมูลต้นทางที่แยกส่วนหรือ mapping ที่ตรวจแล้ว ไม่แยกด้วยการเดาจากช่องว่าง; ส่วนงานอื่นยังอ้างพนักงานด้วย id เดิมและประกอบชื่อเมื่อต้องแสดง
