# เก็บภาพหลักฐานรับดินที่บีบอัดแล้วใน PostgreSQL

ผู้ใช้ยืนยันเมื่อ 26 พฤศจิกายน 2026 ให้รายการรับดินมีภาพหลักฐานอย่างน้อย 1 และไม่เกิน 3 รูป และให้บีบอัดภาพที่จัดเก็บในฐานข้อมูลเพื่อลดการเติบโตของข้อมูล การเลือกเก็บใน PostgreSQL สอดคล้องกับแนวทาง [ภาพชาร์ตสี](0003-color-chart-images-in-postgres.md) ที่ภาพติดไปกับชุดสำรองฐานข้อมูล แทนการเพิ่มที่เก็บไฟล์แยกซึ่งต้องดูแลการสำรองและกู้คืนอีกส่วน

ภาพหลักฐานต้องยังอ่านข้อมูลเอกสารได้ จึงไม่ยกข้อจำกัดความละเอียดและขนาดของภาพตัวอย่างสีมาใช้โดยอัตโนมัติ ขนาดหลังบีบอัด คุณภาพที่ยอมรับ และความจำเป็นในการเก็บต้นฉบับยังต้องกำหนดในแบบรับดิน การบีบอัดภาพอย่างเดียวไม่รับรองความเร็วหน้ารายการ ต้องออกแบบการโหลดภาพให้เหมาะกับการเปิดใช้งานด้วย
