# รวมสต็อกวัตถุดิบตามประเภทดินและเก็บชื่อการค้าในใบรับ

ผู้ใช้ยืนยัน Q19 เมื่อ 26 พฤศจิกายน 2026 ว่าชื่อดินตามเอกสารมีไว้เก็บประวัติ แต่เมื่อรับลงกองแล้วถือเป็นประเภทดิน เช่น ดินขาว จึงเลือกใช้ประเภทดินจากทะเบียนเดิมเป็นตัวตนหลักของสต็อกวัตถุดิบ และเก็บชื่อการค้า/ผู้ขายในใบรับแทนการแยกยอดตามชื่อ ข้อนี้แทนข้อสรุป Q7 เดิม การเบิกเข้าโม่ไม่ต้องระบุชื่อการค้าหรือเที่ยวรับ และไม่ถือว่าสามารถตามวัตถุดิบถึงล็อตต้นทางได้จากยอดรวม

น้ำหนักวัตถุดิบก่อนโม่แยกจากสต็อกแผ่นดินปั๊ม การรับหรือเบิกไม่แปลงกิโลกรัมเป็นจำนวนแผ่น ผู้ใช้ยืนยัน Q20 ให้ปรับยอดคงเหลือจริงด้วยรายการปรับยอดที่มีเหตุผลและประวัติ แยกจากการแก้ข้อมูลรับตามบิล เพื่อรักษาข้อเท็จจริงของเอกสารเดิม

Q21 ยืนยันให้ค่าตรวจนับเป็นข้อเท็จจริง ณ จุดเวลานั้น เมื่อแก้เอกสารก่อนจุดตรวจนับ ต้องคำนวณผลต่างปรับใหม่ให้คงค่าตรวจนับเดิม พร้อมประวัติของผลก่อน–หลัง แทนการตรึงผลต่างเดิมซึ่งจะทำให้การแก้บิลเก่าบิดยอดที่ตรวจนับจริง รายการรับ/เบิกหลังตรวจนับยังมีผลตามปกติ
