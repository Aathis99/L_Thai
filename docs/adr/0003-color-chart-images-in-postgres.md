# เก็บภาพตัวอย่างชาร์ตสีใน PostgreSQL

ชาร์ตสีมีภาพตัวอย่างได้หนึ่งภาพต่อรายการ ผู้ใช้เลือกเก็บภาพพร้อมทะเบียนใน PostgreSQL เพื่อให้ติดไปกับชุดสำรอง Docker และกู้คืนพร้อมชื่อสี การเก็บเป็นไฟล์แยกเหมาะกับภาพต้นฉบับขนาดใหญ่กว่า แต่ต้องขยายขั้นตอนส่งต่อและกู้คืน รุ่นแรกจำกัดขนาดภาพที่จัดเก็บเพื่อให้การเปิดดูและสำรองข้อมูลยังเหมาะกับการใช้งานในโรงงาน
