# แยกสต็อกวัตถุดิบดินตามประเภทดินและผู้ขาย

26 พฤศจิกายน 2026 ผู้ใช้ยืนยัน Q1–Q2 ในการหารือรอบแยกผู้ขายว่า “บริษัท” หมายถึงผู้ขาย และต้องการแยกยอดคงเหลือตามประเภทดินเดิมร่วมกับผู้ขาย แทนการรวมดินประเภทเดียวกันจากทุกผู้ขายตาม ADR 0009 เพื่อดูยอดของแต่ละแหล่งซื้อแยกกัน ชื่อการค้ายังคงเป็นรายละเอียดในใบรับ ไม่แยกยอดเพิ่มตามชื่อการค้า

ข้อนี้แทนเฉพาะการรวมยอดข้ามผู้ขายใน [ADR 0009](0009-raw-clay-stock-by-type.md) กติกาหน่วยน้ำหนัก การตรวจนับ และการแก้เอกสารเดิมยังคงอยู่ ไม่เปลี่ยนการแยกสีดินที่มีอยู่ การแยกยอดตามผู้ขายยังไม่ใช่การติดตามถึงเที่ยวรับหรือล็อตต้นทาง

Q3 และ Q8–Q10 ยืนยันว่าหน้างานแยกกองจริงตามผู้ขาย/ประเภทดิน จึงเลือกหน้าหลักจัดกลุ่มตามผู้ขายและเบิกหนึ่งรายการต่อประเภทดินและผู้ขาย ไม่ต้องระบุเที่ยวรับ ผู้มีสิทธิ์รับดินเพิ่ม/แก้ชื่อผู้ขาย ผู้ดูแลระบบปิดใช้งาน/ลบ/รวมรายชื่อซ้ำ โดยรักษาประวัติ

Q11 ยืนยันแบ่งยอดตั้งต้นเดิมตามผู้ขายสามรายจากหกแถวต้นทาง โดยรักษายอดรวม 66,983 กก. และประวัติ ไม่สร้างรับเข้าซ้ำ Q12 กำหนดสถานะ “หยุดรับเข้า” ให้ซ่อนจากใบรับใหม่ แต่ยังเบิกและปรับยอดกองเดิมได้

เป็นข้อยุติของแบบที่กำลังตรวจยืนยันตาม [แบบเต็ม](../superpowers/specs/2026-11-26-clay-supplier-stock-design.md) ยังไม่อนุมัติพัฒนาหรือนำขึ้นระบบหลัก ระบบที่ใช้งานจริงยังรวมยอดตามประเภทดิน/สีดินเดิม
