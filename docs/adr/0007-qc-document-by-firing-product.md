# ใบ QC รวมตามรอบเผาและสินค้าโดยรักษายอดต้นทาง

ผู้ใช้ยืนยัน Q5–Q7 วันที่ 25 พฤศจิกายน 2026 ให้หนึ่งใบ QC ครอบคลุมรอบเผาหนึ่งรอบสำหรับสินค้า ดิน และสีเดียวกัน โดยคัดหลายครั้งแล้วลงยอดเพิ่มสะสมในใบเดิมได้ แทนการออกใบใหม่ทุกครั้งที่คัด เพื่อให้ตรงกับการจดกระดาษตามงานเตา

งานที่มาจากต่างออเดอร์พิมพ์รวมใบเดียวกันได้ แต่ต้องรักษาผลคัดแยกตามออเดอร์ต้นทาง จึงแยกขอบเขตเอกสารออกจากขอบเขตการติดตามยอด เพื่อให้งานจัดสรร ซ่อม และสต็อกตามที่มาได้ ไม่รวมยอดจนสูญเสียที่มา
