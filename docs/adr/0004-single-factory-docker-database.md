# ใช้ฐาน Docker เดียวสำหรับระบบโรงงาน

คงชุด `lthai-docker` และฐาน `lthai` เดิมเป็นแหล่งข้อมูลหลักของพนักงาน งานปั๊ม และชาร์ตสี เพื่อให้ใช้งานผ่านเว็บเดียวและสำรองพร้อมกัน เมื่อย้ายออกจากชุดทดสอบ ให้นำเข้าเฉพาะทะเบียนที่ผู้ใช้เลือก แทนการกู้ทั้งฐานทับฐานหลัก เพราะประวัติงานปั๊มทดสอบผูกกับพนักงานจำลองและมีผลต่อยอดสต็อก ส่วนภาพทดสอบและประวัติที่ไม่ได้ย้ายเก็บไว้ในชุดสำรองก่อนถอด container ทดสอบ
