# Next.js + Express + PostgreSQL สำหรับระบบโรงงาน

ผู้ใช้เลือก Next.js/React/TypeScript เป็นหน้าบ้าน และ Node.js/Express เป็น API แยก พร้อม PostgreSQL ที่ดูผ่าน DBeaver จะใช้หลายคนบนมือถือและคอมพิวเตอร์ในโรงงาน และต้องทำงานได้เมื่ออินเทอร์เน็ตล่ม จึงเตรียมทั้งแอปและฐานข้อมูลให้รันบนเครื่องในโรงงาน โดยไม่เรียก CDN หรือบริการ cloud ระหว่างใช้งาน

แลกกับการดูแลสอง process และ PostgreSQL เพิ่มจากโครงเดิม แต่ได้ขอบเขต API ที่ชัดสำหรับงานออเดอร์/ผลิตในอนาคต เก็บข้อมูลและ password hash เดิมระหว่างย้าย ไม่สร้างบัญชี login จากรายชื่อพนักงานใน Excel
