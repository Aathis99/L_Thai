# แยกสินค้ากระเบื้องออกจากแบบดินปั๊มและชนิดดิน

ผู้ใช้เลือกเมื่อ 20 พฤศจิกายน 2026 ให้ทะเบียนแสดงสินค้าแต่ละแบบครั้งเดียวและเลือกชนิดดินเมื่อเปิดใบสั่งปั๊ม โดยเก็บค่าผลิตแยกตามดิน แทนการให้ผู้ใช้ดูแลรายละเอียดสินค้าเดียวกันซ้ำสี่รายการ สินค้าต่างรหัสที่ต่างเฉพาะลายวาดสามารถใช้แบบดินปั๊มและสต็อกดินร่วมกันเมื่อหน้างานยืนยัน แต่สินค้าปลายทางยังแยกรหัสเดิมครบ จึงแยกเอกลักษณ์สินค้าออกจากแบบดินปั๊มและประเภทผลิตซึ่งรวมชนิดดิน/สีดิน การจัดกลุ่มทะเบียนไม่ใช่การรวม primary key หรือรวมสต็อกดินต่างชนิด ประเภทเดิมที่มีประวัติอ้างอิงต้องรักษาตัวตนไว้ เหตุผลและขอบเขตการพัฒนาอยู่ใน [ร่างแบบทะเบียนกระเบื้อง](../superpowers/specs/2026-11-20-tile-catalog-design.md) ซึ่งยังรอตรวจและอนุมัติแบบก่อนพัฒนา
