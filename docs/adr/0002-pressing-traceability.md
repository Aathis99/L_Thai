# ติดตามงานปั๊มตามใบสั่งผลิตและรายการปั๊ม

ผู้ใช้เลือกให้รุ่นแรกบันทึกผู้ปั๊มและวันที่ตามใบสั่งผลิต ใช้การเบิกที่ยืนยันแล้วคุมสต็อก และสรุปของเสียตามงานเผา วิธีนี้ใช้กับการจดหน้างานปัจจุบันได้โดยไม่ต้องให้ทุกขั้นตอนรักษาเลขชุดไว้ เมื่อแผ่นจากหลายรายการถูกนำไปคัดรวมกันแล้ว ระบุผู้ปั๊มได้เฉพาะส่วนที่มีข้อมูลอ้างอิงจริง การติดเลขชุดในอนาคตจะเพิ่มความละเอียดให้รายการใหม่ตั้งแต่วันที่เริ่มใช้
