# แผนพัฒนางานชุบเคลือบ งานเตา และ QC

แบบที่ยืนยันอยู่ใน [แบบงานชุบเคลือบและงานเตา](../specs/2026-11-16-glazing-kiln-design.md)

- [x] ขยายใบสั่งผลิตและการเบิกให้เก็บออเดอร์ สี ยอดเผื่อ จำนวนแผ่นต่อตารางเมตร และการย้ายยอด พร้อมตรวจรับใบค้างก่อนเริ่มใช้
- [x] บันทึกชุดชุบจากยอดสุทธิของใบเบิก ตรวจผลรวมและผู้ทำงาน ทดสอบการบันทึกซ้ำและการคืนยอดที่ใช้แล้ว
- [x] เพิ่มช่วงอุณหภูมิและรอบเผา รองรับชุดชุบและบรีส ตรวจอุณหภูมิขอบช่วงและการแบ่งลงหลายรอบ
- [x] บันทึกผลคัดรายรายการหรือกองคัดรวม เก็บที่มาและตรวจยอดสะสม จัดสรรแผ่นดีและยืนยันส่วนเกินเข้าสต็อก
- [x] เชื่อมหน้าจอและสิทธิ์ ตรวจเส้นทางงานและประวัติบนเว็บ QA ทั้งเดสก์ท็อปและมือถือ

## วิธีเปิดตรวจรับ

เปิด `http://127.0.0.1:3129` และเข้าด้วยบัญชีจากชุดสำรอง ดูยอดตัวอย่างที่เมนู **งานชุบ เตา และ QC → พร้อมส่งและสต็อก** โดยเลขอ้างอิงออเดอร์ทดสอบขึ้นต้นด้วย `QA-BROWSER-` ทดสอบใบใหม่จากเมนู **งานปั๊ม → ใบสั่งผลิต** แล้วเปิดใบเบิกผูกกับใบสั่ง ในงานเตาตั้งช่วงดินและสีที่ใช้ก่อนลงเตารอบแรก

ใช้ transaction และการตรวจสิทธิ์ซ้ำของ API เดิม เก็บตารางกระบวนการใหม่แยกจากประวัติผลคัดเดิม ทดสอบกับฐานที่กู้จาก Docker และตรวจชื่อฐานก่อนรันทุกชุดที่เขียนข้อมูล ตรวจรับกับผู้ใช้ก่อนนำขึ้นฐานหลัก
