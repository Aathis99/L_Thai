# ข้อเสนอประเภทและสีปุ่ม

สถานะ ผู้ใช้ตรวจรับและเปิดใช้งานบน lthai-docker พอร์ต 3001 เมื่อ 18 พฤศจิกายน 2026

## ขอบเขต

ผู้ใช้ตรวจรับหน้าตาโหมดมืดแล้ว ขอสำรวจปุ่มและเสนอสีตามหน้าที่สำหรับใช้ร่วมกันทุกหน้า ข้อเสนอนี้ครอบคลุม Light และ Dark

## สิ่งที่พบจากโค้ด

นับรูปแบบที่ใช้จริงพร้อม modifier danger และ selected ได้ 13 แบบ ได้แก่ primary, secondary, secondary danger, destructive, quiet, icon-button, table-button, table-button danger, nav-item, nav-item selected, theme-toggle, chart-entry และ chart-image-retry การนับนี้แยกตามรูปแบบ CSS โดยไม่นับ hover, disabled หรือขนาดจอเป็นแบบเพิ่ม

ปุ่มเพิ่ม บันทึก และแท็บที่เลือกใช้ primary ร่วมกัน ส่วน helper action ใน finishing/shared.tsx กำหนด secondary ให้ทั้งบันทึก แก้ไข ย้อนรายการ และไปหน้าอื่น FormDialog เลือก destructive เฉพาะ HTTP DELETE ทำให้คำสั่งย้อนยอดแบบ POST แสดงปุ่มยืนยันสีหลักด้วย

## ประเภทตามหน้าที่ที่เสนอ

สีในตารางคือพื้นหลังหลักของปุ่ม ส่วนปุ่มคำสั่งย่อยในตารางใช้ข้อความสีเดียวกันบนพื้นโปร่งหรือพื้นอ่อน เพื่อลดความแน่นของหน้าจอ

| ประเภท | ตัวอย่าง | พื้น Light / ข้อความ | พื้น Dark / ข้อความ |
| --- | --- | --- | --- |
| เพิ่มหรือสร้าง | เพิ่มพนักงาน เพิ่มใบสั่งผลิต | #245bb5 / #ffffff | #8ab4f8 / #16181b |
| บันทึกหรือยืนยัน | บันทึกข้อมูล ยืนยันรับเข้า | #237044 / #ffffff | #81c995 / #16181b |
| แก้ไขหรือปรับรายการ | แก้ไข ปรับยอด ย้อนเบิก ย้อนรับเข้า | #8a5700 / #ffffff | #d9b56f / #16181b |
| ลบหรือหยุดใช้ | ลบใบสั่งผลิต ลบภาพ หยุดใช้ประเภท | #b33d3d / #ffffff | #e89595 / #16181b |
| คำสั่งรองและเครื่องมือ | ปิด ยกเลิกฟอร์ม ประวัติ โหลดใหม่ เปลี่ยนธีม | #edf0f4 / #344054 | #2a2e34 / #e4e7eb |
| เมนูหรือแท็บ | เมนูและแท็บที่กำลังเลือก | #e8f0ff / #245bb5 | #26364d / #a8c7fa |

ไอคอนเป็นรูปแบบของปุ่มและใช้สีตามหน้าที่ เช่น ถังขยะสีแดงและปิดหน้าต่างสีกลาง กำลังทำงานและกดไม่ได้เป็นสถานะของทุกประเภท ปุ่มมีข้อความหรือชื่อสำหรับโปรแกรมอ่านหน้าจอและมีกรอบ focus

การยกเลิกฟอร์มเป็นคำสั่งรอง ส่วนยกเลิกผลคัดหรือย้อนยอดที่บันทึกไปแล้วจัดเป็นการแก้ไขหรือปรับรายการสีอำพัน ปุ่มที่ลบแถวร่างภายในฟอร์มใช้คำสั่งรอง ปุ่มยืนยันใน dialog ใช้สีตามการกระทำจริง

ภาพเทียบสีอยู่ใน `data/button-palette-proposal.png` และต้นแบบใน `data/button-palette-proposal.html` ใช้สำหรับเลือกแบบ

## จุดที่รอตกลง

- ใช้หกกลุ่มและสีที่เสนอร่วมกันทั้งสองโหมดหรือปรับส่วนใด
- ใช้สีอำพันกับการย้อนยอดและยกเลิกผลคัดที่บันทึกแล้วตามกลุ่มปรับรายการหรือไม่

เมื่อเลือกแบบแล้วให้กำหนด color tokens กลางและส่ง intent ให้ปุ่มและ FormDialog โดยอิงความหมายการกระทำ ตรวจการใช้ทุกจุดบน QA และให้ผู้ใช้ตรวจรับก่อนอัปเดตชุดหลักตาม AGENTS.md

เก็บประเภท UI ทั่วไปในแบบนี้ตามเกณฑ์ domain-modeling ส่วน GLOSSARY.md ใช้ศัพท์เฉพาะโรงงาน
