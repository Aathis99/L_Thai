# ลบใบสั่งผลิตที่ยังไม่ถูกใช้

ผู้ใช้ยืนยันแบบวันที่ 13 พฤศจิกายน 2026

ผู้ใช้ต้องการเอาใบสั่งผลิตที่สร้างผิดหรือซ้ำออกจากรายการงาน ขอบเขตที่ตกลงคือใบสั่งผลิตที่ยังไม่มีรายการปั๊มหรือรายการเบิกอ้างถึง ใช้กับทั้งใบตามออเดอร์ลูกค้าและใบที่สั่งปั๊มเข้าสต็อก การจัดการใบที่เริ่มงานแล้วเป็นเรื่องแยกจากแบบนี้

## ทางเลือก

- ลบใบที่ยังไม่ถูกใช้และบันทึกประวัติการลบ เป็นทางเลือกที่ผู้ใช้เลือกเพื่อแก้กรณีสร้างผิดหรือซ้ำโดยตรง
- เก็บใบไว้แล้วซ่อนจากรายการงาน วิธีนี้เก็บข้อมูลใบเดิมครบและเปิดทางให้กู้คืนได้ แต่ต้องกำหนดว่ารายการไหนยังมองเห็นหรือเลือกใบที่ซ่อนได้

## พฤติกรรมที่เสนอ

- ใช้สิทธิ์จัดการงานปั๊มเดิม หน้าใบสั่งผลิตแสดงปุ่ม **ลบใบสั่งผลิต** สำหรับใบที่ลบได้ ข้อความยืนยันแสดงเลขใบ ประเภทกระเบื้อง และยอดสั่งปั๊ม พร้อมปุ่ม **ยกเลิก** และ **ยืนยันลบ** โดยไม่ต้องกรอกเหตุผล
- สำหรับใบที่มีรายการอ้างถึง ให้แสดงเหตุผลสั้น ๆ ว่ามีรายการปั๊มหรือรายการเบิกแล้ว
- เมื่อยืนยัน ให้ API ตรวจสิทธิ์และตรวจรายการอ้างอิงจากข้อมูลล่าสุดในธุรกรรมเดียวกับการลบและบันทึกประวัติ ถ้ามีรายการปั๊มหรือรายการเบิกแม้เพียงรายการเดียว ให้ปฏิเสธ แจ้งเหตุผล และโหลดรายการใหม่ ยอดที่ปรับเป็นศูนย์หรือรายการเบิกที่ย้อนแล้วก็ยังถือว่ามีประวัติ
- เมื่อลบสำเร็จ ให้เอาใบออกจากรายการและตัวเลือกที่ใช้งาน พร้อมเก็บผู้ลบ เวลา เลขใบ ประเภทกระเบื้อง ยอดสั่งปั๊ม และเลขอ้างอิงลูกค้าเมื่อมี ไว้ในประวัติการเปลี่ยนแปลงเดิม

## ตรวจรับ

- ยกเลิกจากหน้าต่างยืนยันแล้วใบยังอยู่ ยืนยันลบใบที่ยังไม่ถูกใช้แล้วใบหายจากรายการและมีประวัติการลบ ตรวจทั้งใบตามออเดอร์ลูกค้าและใบปั๊มเข้าสต็อก
- ใบที่มีรายการปั๊ม ใบที่มีรายการเบิกจากสต็อกเดิมแม้ยังไม่ลงยอดปั๊ม และใบที่รายการเบิกถูกย้อนแล้ว ลบไม่ได้ ยอดสต็อกและประวัติยังตรงกับก่อนกดลบ
- ถ้าอีกคนลงยอดหรือเบิกหลังเปิดหน้าต่างยืนยัน คำขอลบต้องถูกปฏิเสธ บัญชีที่มีสิทธิ์ดูอย่างเดียวเรียก API ลบไม่ได้
- ตรวจรับด้วยฐาน QA แยกที่กู้จากชุดสำรองใหม่ของ Docker ตามกติกาโครงการ
