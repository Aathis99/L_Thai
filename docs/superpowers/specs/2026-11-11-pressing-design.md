# แบบระบบงานปั๊มรุ่นแรก

ผู้ใช้ยืนยันแบบ 11 พฤศจิกายน 2026 อ้างอิง [คำตอบจากหน้างาน](../../discovery.md) และ [คำศัพท์โรงงาน](../../../GLOSSARY.md)

## เป้าหมายและขอบเขต

ให้ธุรการบันทึกยอดปั๊มครั้งเดียว แล้วใช้ข้อมูลชุดเดียวกันดูความคืบหน้าของใบสั่งผลิต ยอดคงเหลือ วันครบกำหนดพัก และการเบิกไปขั้นตอนถัดไป ผลคัดหลังเผาใช้สรุปยอดดีและเสียตามงานเผา

รุ่นแรกมีทะเบียนประเภทกระเบื้อง ใบสั่งผลิต บันทึกยอดปั๊ม สต็อกและการเบิก และบันทึกผลคัดหลังเผา งานสีและงานเตาเป็นปลายทางของการส่งต่อ ใบสั่งผลิตเก็บเลขอ้างอิงออเดอร์จากงานขายและใช้ระบบบัญชีและสิทธิ์เดิมผ่านเว็บในเครือข่ายโรงงาน ส่วนค่าแรงเหมา ต้นทุนดิน ระบบออเดอร์ลูกค้าเต็มรูปแบบ และการนำเข้าประวัติผลิตย้อนหลังเป็นงานภายหลัง

## แนวทางที่เลือก

| ทางเลือก | ผลต่อหน้างาน |
| --- | --- |
| ตามใบสั่งผลิตและรายการปั๊ม | ลงตามวันที่และผู้ปั๊ม ใช้รายการปั๊มและยอดตั้งต้นเป็นที่มาของสต็อก เก็บการเบิกและผลคัดตามรายการที่ยืนยันได้ |
| ตามเลขชุดตั้งแต่ปั๊มถึงคัด | ติดเลขบนไม้หรือกอง รักษาการอ้างอิงเมื่อผ่านสี เข้าเตา และคัด ตามกลับได้ละเอียดเมื่อหน้างานแยกชุดได้ตลอด |

ผู้ใช้เลือกทางแรกเพื่อให้ใช้การจดหน้างานปัจจุบันได้ และเก็บผู้ปั๊มในยอดเสียเมื่อมีข้อมูลตามกลับได้ ผู้บันทึกกับคนปั๊มเป็นคนละหน้าที่ รายการปั๊มในระบบจึงเก็บทั้งผู้ปั๊มจริงและบัญชีผู้บันทึก [เหตุผลที่เลือกวิธีติดตาม](../../adr/0002-pressing-traceability.md)

## ข้อมูลที่กรอกและยอดที่ระบบคำนวณ

| งาน | ข้อมูลที่กรอกหรือเลือก | ข้อมูลที่ระบบแสดงหรือคำนวณ |
| --- | --- | --- |
| ทะเบียนประเภทกระเบื้อง | ขนาดสองด้าน ประเภทดิน (แดง ขาว จ้อ สี) ชื่อเรียกถ้ามี จำนวนแผ่นต่อไม้ จำนวนวันพัก และปลายทางเบิก เก็บรายละเอียดดินสีและอัตราแผ่นต่อ ตร.ม. เมื่อยืนยันได้ | รายการประเภทที่ใช้เลือกในใบสั่งผลิตและแสดงในสต็อก |
| ใบสั่งผลิต | ประเภทกระเบื้อง ยอดสั่งปั๊มเป็นแผ่น และที่มาว่าผลิตตามออเดอร์ลูกค้าหรือปั๊มเก็บสต็อก งานตามออเดอร์ใส่เลขอ้างอิงจากงานขาย | ยอดปั๊มสะสมจากทุกรายการในใบสั่ง ยอดที่ยังขาด และยอดปั๊มเกิน |
| บันทึกยอดปั๊ม | ใบสั่งผลิต วันที่ปั๊ม ผู้ปั๊มจริง จำนวนไม้เต็ม แผ่นเศษถ้ามี และหมายเหตุ | จำนวนไม้เต็ม × แผ่นต่อไม้ + แผ่นเศษ แปลงเป็น ตร.ม. เมื่อมีอัตราที่ตรวจแล้ว และแสดงวันที่ครบกำหนดพักตามวันที่ปั๊ม |
| เบิกจากสต็อกงานปั๊ม | ประเภทกระเบื้อง ยอดต้นทาง จำนวนที่จะเบิก และปลายทาง ผู้เบิกตรวจความพร้อมจริงก่อนยืนยัน | ยอดคงเหลือของรายการหลังเบิก วันครบกำหนดพัก และประวัติว่าใครยืนยันเบิกเมื่อไร |
| ผลคัดหลังเผา | อ้างอิงงานเผา ประเภท วันที่เผา วันที่คัดเสร็จ จำนวนแผ่นดีและเสีย และรายการเบิกหรือผู้ปั๊มเมื่อหน้างานตามกลับได้ | ยอดดีและเสียของงานเผาเมื่อส่งผลคัดครบ พร้อมวันที่ส่งยอด |

สีชุบหรือสีเคลือบระบุที่งานสี ส่วนรายละเอียดสีของเนื้อดินใช้บอกว่าปั๊มด้วยดินอะไร ประเภทที่ใช้แผ่นหลังปั๊มแทนกันได้ใช้ยอดงานปั๊มร่วมกัน ทะเบียนมีตัวระบุที่คงเดิมเมื่อแก้ชื่อ รายการที่มีประวัติให้หยุดใช้จากหน้าทะเบียนและเปิดดูข้อมูลเดิมได้ ประเภทที่ยังไม่มีการอ้างอิงลบได้ จำนวนแผ่นต่อไม้ จำนวนวันพัก และอัตราแปลงที่ใช้กับรายการเดิมต้องตรวจย้อนกลับได้หลังแก้ทะเบียน

## การนับสต็อกและส่งต่อ

1. ธุรการเลือกใบสั่งผลิตแล้วลงยอดตามผู้ปั๊มจริง เมื่อบันทึกสำเร็จ จำนวนแผ่นเข้าสู่สต็อกงานปั๊มทันที หนึ่งใบสั่งมีหลายรายการได้ เช่น วันนี้คนหนึ่งทำ 3,000 แผ่นและพรุ่งนี้อีกคนทำ 3,000 แผ่น ยอดรวมของใบสั่งคือ 6,000 แผ่น
2. สต็อกแสดงจำนวนคงเหลือแยกตามประเภทและวันที่ปั๊ม พร้อมวันที่ครบกำหนดพัก ตัวอย่างประเภทพัก 4 วัน ยอด 1,500 แผ่นเข้าคงเหลือตั้งแต่วันปั๊มและแสดงว่ารอเซ็ตตัวในช่วงพัก เมื่อถึงกำหนดผู้เบิกตรวจสภาพจริงและยืนยันการเบิก ยอดตั้งต้นที่ไม่ทราบวันปั๊มให้แสดงตามข้อมูลที่ยืนยันและให้ผู้รับผิดชอบยืนยันความพร้อมก่อนนำไปเบิก
3. ผู้เบิกเลือกจำนวนและรายการต้นทางที่สัมพันธ์กับกองจริงตามข้อมูลที่มี แล้วเลือกปลายทางตามประเภท งานที่ทำสีส่งไปชุบหรือเคลือบ บรีสส่งเข้าเตาหลังรอเซ็ตตัว เมื่อยืนยันสำเร็จจึงตัดยอดตามจำนวนที่เบิก เบิกบางส่วนได้ ยอดคงเหลือทุกแหล่งต้องไม่ติดลบ และการส่งคำขอซ้ำต้องไม่ตัดยอดซ้ำ
4. แสดงยอดสั่งและยอดทำจริงควบคู่กัน ถ้าสั่ง 1,000 แผ่นแต่ปั๊มเต็มไม้ได้ 1,500 แผ่น ยอดรับเข้าคือ 1,500 แผ่นและยอดเกินคือ 500 แผ่น ผู้รับผิดชอบเป็นผู้ยืนยันจำนวนส่วนเกินที่จะปล่อยไปใช้กับงานอื่น การปล่อยเปลี่ยนสิทธิ์นำยอดเดิมไปใช้และคงยอดคงเหลือรวมเท่าเดิม
5. หน้างานส่งผลคัดเมื่อคัดหลังเผาครบ เช่น เผาวันหนึ่ง คัดวันถัดไป แล้วส่งยอด ผลที่ส่งแล้วนับของเสียที่งานเผา จำนวนที่เบิกจากงานปั๊มถูกตัดเมื่อยืนยันเบิกแล้ว เช่น เบิก 1,500 แผ่นและหลังเผาคัดได้ดี 1,480 เสีย 20 รายงานงานเผาแสดงดี 1,480 เสีย 20 และสต็อกฝั่งปั๊มยังลดเท่ากับ 1,500 ตามใบเบิกเดิม ถ้าคัดรวมจนไม่รู้ว่าเป็นของใคร ให้ลงยอดเสียระดับงานเผา

## ข้อมูลจาก Excel

ใช้ไฟล์ต้นทางเพื่อตรวจข้อมูลตั้งต้นและออกแบบช่องกรอก ตารางปั๊มเดือนล่าสุดที่ตรวจคือ `พ.ย.69` หัวคอลัมน์เปลี่ยนไปตามเดือน จึงอ้างคอลัมน์ด้านล่างเฉพาะชีตนี้

| แหล่ง | ใช้ในรุ่นแรก |
| --- | --- |
| `ยอดปั๊มแผ่น-2569.xlsx` ชีต `พ.ย.69` คอลัมน์ E:G ขนาด ชนิดดิน ดินสี และ K แผ่นต่อไม้ | ใช้เสนอรายการทะเบียนและอัตราต่อไม้ ตรวจรายการซ้ำและอัตราที่ต่างกันกับหน้างานก่อนใช้จริง จำนวนวันพัก ชื่อเรียก และปลายทางเติมจากหน้างาน |
| ชีตเดียวกัน คอลัมน์ C:D วันที่และชื่อ และ J จำนวนไม้ | ใช้เป็นแบบของข้อมูลที่ธุรการกรอกในระบบ วันปั๊มแยกจากเวลาบันทึก เลือกชื่อผู้ปั๊มจากทะเบียนพนักงานที่มีอยู่ |
| ชีตเดียวกัน คอลัมน์ L:N จำนวนแผ่น แผ่นต่อ ตร.ม. และ ตร.ม. | ตรวจเทียบสูตรและอัตราแปลง จำนวนแผ่นและพื้นที่ของรายการใหม่ให้ระบบคำนวณ |
| ชีตเดียวกัน คอลัมน์ A:B, H:I, O:V และตารางด้านขวา Z:AS | ใส่หมายเหตุตามความจำเป็น สีเคลือบใช้ในขั้นตอนงานสี ค่าแรงและต้นทุนเลื่อนไปก่อน ใช้ตารางด้านขวาเพื่อเข้าใจข้อมูลของเสีย โดยอ้างงานเผาจริงสำหรับยอดใหม่ `PLANT` ใช้เป็นข้อมูลประกอบจนยืนยันความหมายและจุดเก็บที่เกี่ยวข้อง |
| `สต็อกคงเหลือ.xlsx` ตารางรายเดือน เช่น `พย69` หัวกลุ่ม A1:J4 และยอดปิด IQ1:IY4 | ใช้เทียบยอดตั้งต้นตามประเภท ณ วันที่ที่หน้างานยืนยัน ระบุว่าตัวเลขเป็นสต็อกงานปั๊มช่วงไหน และยืนยันว่าพร้อมเบิกหรือยัง |
| ไฟล์สต็อก ส่วนบรีส และ `Sheet1` ที่หักออเดอร์ | ใช้ประกอบการตรวจสอบ ส่วนบรีสต้องยืนยันว่าตัวเลขนับของขั้นตอนไหน ชีตหักออเดอร์ใช้ดูความหมายของยอดที่กันงานและแยกจากยอดกองจริง |

ก่อนตั้งยอดเปิดใช้ ให้ตรวจวันที่และจำนวนกับหน้างาน รวมถึงปีในหัววันที่ของไฟล์สต็อก ระบุประเภทและขั้นตอนสำหรับแต่ละยอด แล้วบันทึกยอดตั้งต้นครั้งเดียวต่อแหล่งที่ยืนยัน รายการชื่อ “ศิลาแลง” รอเทียบกับชื่อในทะเบียนก่อนใช้ ไฟล์ Excel และข้อมูลตรวจนำเข้าอยู่ภายนอก Git

## กติกาที่ใช้ในรุ่นแรก

- เริ่มจากใบสั่งผลิตหนึ่งประเภทต่อใบ ออเดอร์ที่มีหลายประเภทอ้างเลขเดียวกันได้จากหลายใบ ความคืบหน้าใบสั่งผลิตใช้ยอดปั๊ม ส่วนผลดีหลังเผาดูจากผลคัด
- ยอดที่ผลิตตามออเดอร์ผูกกับใบสั่งผลิตเดิมจนกว่าผู้รับผิดชอบจะปล่อยส่วนเกินที่ยังเหลือเข้ายอดสำหรับงานอื่น ยอดผลิตเก็บสต็อกใช้กับงานอื่นได้เมื่อพร้อมเบิก หากปรับแผนหลังปั๊มแล้ว ให้ผู้รับผิดชอบยืนยันการจัดสรรใหม่โดยเก็บประวัติเดิม
- ยืนยันเบิกได้ตั้งแต่วันที่ครบกำหนดพัก ผู้เบิกตรวจของจริงอีกครั้ง ยอดตั้งต้นที่ไม่ทราบวันปั๊มใช้สถานะที่หน้างานยืนยัน หากเบิกจากกองรวมและแยกต้นทางจริงไม่ได้ ให้บันทึกว่าเบิกจากกองรวมและตัดจากยอดที่มีสิทธิ์เบิกตามประเภทและใบสั่ง การจัดยอดนี้ใช้คุมสต็อก ส่วนผู้ปั๊มในผลเสียเว้นไว้จนมีข้อมูลตามงานจริง
- ใช้เลขอ้างอิงงานเผาที่หน้างานมี หรือให้ระบบออกเลขถ้ายังไม่มี งานเผาหนึ่งงานมีผลคัดได้หลายประเภท ให้ส่งยอดที่คัดครบแยกตามประเภท การแก้ผลที่ส่งแล้วเก็บประวัติและใช้ผลล่าสุดในการรวมยอด
- แก้รายการปั๊มที่ยังไม่ถูกเบิกได้โดยเก็บประวัติ หลังมีการเบิกให้ผู้มีสิทธิ์ลงรายการปรับยอดอ้างอิงรายการเดิม และตรวจว่าจำนวนที่แก้ยังครอบคลุมยอดที่เบิกหรือปล่อยไปใช้แล้ว ถ้าข้อมูลเบิกผิดให้แก้รายการเบิกที่เกี่ยวข้องก่อน
- แยกสิทธิ์จัดการทะเบียนและใบสั่ง บันทึกยอดปั๊ม ยืนยันเบิก ปล่อยยอดเกิน ส่งผลคัด และดูรายงาน โดยกำหนดให้บทบาทจริงก่อนเริ่มใช้
- ให้ผู้ทำแผนเลือกวิธีจัดเก็บ การตรวจยอดเมื่อบันทึกพร้อมกัน หน้าจอ รายละเอียดสิทธิ์ และวิธีลงยอดตั้งต้นครั้งแรกตามโครงของระบบเดิม

## ตัวอย่างตรวจรับ
