# เลขประจำตัวพนักงาน

สถานะ ผู้ใช้ตรวจรับและเปิดใช้บน lthai-docker พอร์ต3001 เมื่อ18พฤศจิกายน2026

ผู้ใช้ยืนยันให้แก้สองช่อง ได้แก่ เลขประกันสังคม และเลขประจำตัวประชาชนผู้เสียภาษีอากร ทั้งสองเว้นว่างได้ เมื่อกรอกต้องเป็นเลข 0–9 ครบ 13 หลัก และรับได้สูงสุด 13 หลัก

ใช้ช่องข้อความร่วมกันสำหรับเลขทั้งสอง เพื่อรักษาศูนย์นำหน้า เปิดแป้นตัวเลขบนมือถือ กรองตัวอักษรขณะพิมพ์และวางข้อความ พร้อม pattern ตรวจความครบก่อนส่ง ใช้ในฟอร์มเพิ่มและแก้ไขซึ่งใช้ component เดียวกัน ช่องอื่นใช้ Field เดิม

ผู้ใช้ตรวจรับสองช่องเลขประจำตัวแล้ว และเพิ่มให้เบอร์โทรรับเฉพาะตัวเลขครบ 10 หลัก สูงสุด 10 หลัก ใช้ DigitField ร่วมกันโดยระบุจำนวนหลัก ผู้พัฒนาคงการเว้นว่างของเบอร์โทรตามฟอร์มเดิม เมื่อเปิดแก้ไขเบอร์เดิมให้เอาเว้นวรรค ขีด และวงเล็บออกจากค่าในฟอร์มเพื่อกรอกเป็นตัวเลข ชุดข้อมูลเก็บรักษาเป็นข้อความเพื่อคงศูนย์นำหน้า

API เดิมตรวจค่าว่างหรือ13หลักและรองรับการจัดรูปแบบด้วยเว้นวรรค/ขีด คงพฤติกรรมเดิมสำหรับผู้เรียก API เดิม ตรวจรอบบันทึกและอ่านกลับบน QA โดยไม่เปลี่ยนฐานข้อมูล

เกณฑ์ตรวจรับ ได้แก่ ว่างบันทึกได้ 12หลักส่งไม่ได้ 13หลักส่งได้ 14หลักพิมพ์เกินไม่ได้ ตัวอักษรไม่ค้างในช่อง วางข้อมูลพร้อมเครื่องหมายแล้วเหลือเฉพาะตัวเลข เก็บศูนย์นำหน้า และแก้ไขหรือล้างค่ากลับเป็นว่างได้ ทดสอบบนฐานที่กู้จากสำรองใหม่ตาม AGENTS.md
