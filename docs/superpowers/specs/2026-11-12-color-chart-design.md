# แบบระบบชาร์ตสีรุ่นแรก

ผู้ใช้ยืนยันแบบแล้ว อ้างอิง [บันทึกความต้องการ](../../discovery.md#ชาร์ตสี) และ [คำศัพท์โรงงาน](../../../GLOSSARY.md)

## เป้าหมาย

นำรายชื่อชาร์ตสีจาก Excel มาตั้งต้นทะเบียนกลางของโรงงาน ให้ค้นหา เพิ่ม ลบ และแก้ไขรายการได้ บันทึกชื่อได้ทันทีแม้ยังไม่มีภาพ แล้วกลับมาใส่ภาพตัวอย่างได้หนึ่งภาพต่อรายการ งานสีสามารถอ้างทะเบียนนี้เมื่อพัฒนาขั้นตอนเลือกสีในอนาคต

## หน้าชาร์ตสี

เปิดเมนู **ชาร์ตสี** เพื่อดูรายการเรียงตามลำดับเดิม มีช่องค้นหาจากชื่อเต็มทั้งไทยและอังกฤษ แต่ละแถวแสดงลำดับ ชื่อ รูปย่อเมื่อมี และเครื่องหมายหมายเหตุเมื่อมีข้อความเตือน ช่องรูปที่ยังว่างแสดง “ยังไม่มีภาพ”

```text
ชาร์ตสี                         [ เพิ่มรายการ ]
[ ค้นหาชื่อสีกระเบื้อง                         ]
ลำดับ   ภาพ            ชื่อสีกระเบื้อง
1       ยังไม่มีภาพ    ดินแดง (TERRA COTTA)
2       ยังไม่มีภาพ    ดินแดงเคลือบใส (GLOOSSY GLAZED TERRA COTTA)
```

หน้ารายละเอียดแสดงชื่อเต็ม ภาพตัวอย่าง และหมายเหตุ ผู้มีสิทธิ์จัดการแก้ชื่อและหมายเหตุ อัปโหลด เปลี่ยน หรือลบภาพได้ การลบภาพจะคืนสถานะ “ยังไม่มีภาพ” ของรายการเดิม การลบรายการมีหน้าต่างยืนยันและลบภาพของรายการนั้นไปด้วยในรุ่นแรก หากมีงานผลิตอ้างอิงในอนาคต ให้เปลี่ยนรายการนั้นเป็นหยุดใช้และเก็บข้อมูลให้เปิดดูจากประวัติเดิมได้

ใช้ระบบบัญชีเดิม กำหนดสิทธิ์ **ดูชาร์ตสี** และ **จัดการชาร์ตสี** ผู้ดูเปิดรายการและภาพได้ ผู้จัดการต้องมีสิทธิ์ทั้งสองอย่างเพื่อเพิ่ม แก้ ลบ และจัดการภาพ ผู้ดูแลระบบมีสิทธิ์เริ่มต้น แล้วกำหนดสิทธิ์ให้บทบาทอื่นตามหน้าที่

## ข้อมูลทะเบียนและการนำเข้า

- รายการหนึ่งมีรหัสภายในคงที่ ลำดับแสดงผล ชื่อเต็มที่จำเป็นต้องกรอก หมายเหตุถ้ามี และภาพที่อาจว่าง ลำดับ Excel ใช้แสดงผลและอ้างกลับไปยังต้นทาง รายการใหม่ต่อท้ายลำดับเดิม
- เก็บชื่อไทยและอังกฤษในช่องเดียวตาม Excel ตัดช่องว่างที่หัวท้ายได้ ชื่อที่ต่างกันเฉพาะตัวพิมพ์หรือช่องว่างให้แจ้งว่าเป็นชื่อซ้ำก่อนบันทึก รายการเคลือบใสและชื่อแบบเดิมคงแยกตามไฟล์
- อ่าน `ชาร์ตสี.xlsx` จาก `Sheet1!A3:B92` โดยใช้คอลัมน์ A เป็นลำดับ 1–90 และคอลัมน์ B เป็นชื่อเต็ม นำเข้าครบ 90 รายการรวม “วาดลาย” ลำดับ 64 ภาพเริ่มต้นว่างทั้งหมด
- ใช้ข้อความใน `B95` เป็นหมายเหตุของขาวฟ้า และข้อความใน `B96` เป็นหมายเหตุเดียวกันสำหรับเขียวศิลาดลและศิลาดล หน้ารายละเอียดแสดงเป็นข้อความเตือนจากชาร์ตสีสำหรับอ่านอ้างอิง
- ผู้ดูแลโครงการเตรียมข้อมูลนำเข้าครั้งเดียวด้วยคำสั่งตั้งต้นนอกหน้าเว็บ คล้ายการเตรียมข้อมูลทะเบียนพนักงาน ส่งรายการให้ตรวจลำดับ ชื่อ จำนวน และหมายเหตุก่อนลงฐาน และลองบนฐานทดสอบแยกก่อน เมื่อยืนยันแล้วบันทึกทั้งชุดพร้อมกัน การลองนำเข้าชุดเดิมซ้ำให้แจ้งว่าเคยนำเข้าแล้วและคงรายการที่แก้ไขภายหลัง ถ้าพบเลขลำดับผิด ชื่อซ้ำ หรือชนกับทะเบียนที่มีอยู่ ให้แจ้งรายการที่ต้องตรวจโดยไม่ลงข้อมูลบางส่วน เก็บไฟล์ Excel และข้อมูลเตรียมนำเข้าภายนอก Git

## วิธีเก็บภาพ

ผู้ใช้เลือกเก็บภาพใน PostgreSQL เพื่อให้กู้คืนพร้อมชื่อสีด้วยชุดสำรองเดิม อีกทางที่พิจารณาคือเก็บไฟล์แยก ซึ่งเก็บต้นฉบับขนาดใหญ่ได้สะดวกกว่าและต้องเพิ่มขั้นตอนรวมไฟล์รูปในชุดส่งต่อ [เหตุผลที่เลือก](../../adr/0003-color-chart-images-in-postgres.md)

เก็บข้อมูลภาพแยกจากข้อมูลรายการภายในฐานเดียวกัน ให้เว็บทยอยโหลดรูปย่อเมื่อแถวอยู่ใกล้ส่วนที่ผู้ใช้กำลังดู และตรวจสิทธิ์ดูชาร์ตสีก่อนส่งภาพ ข้อเสนอเริ่มต้นคือรับ JPEG, PNG หรือ WebP ขนาดไฟล์ต้นทางไม่เกิน 8 MiB ตรวจว่าเปิดเป็นภาพได้และย่อเป็นภาพตัวอย่างด้านยาวไม่เกิน 1,024 พิกเซล เก็บภาพที่ได้ไม่เกิน 256 KiB เพื่อคุมขนาดชุดสำรอง หากไฟล์ใช้ไม่ได้ให้แจ้งข้อผิดพลาดและคงรูปก่อนหน้าไว้ ผู้ใช้บันทึกชื่อและแนบภาพแยกกันได้ วิธีเข้ารหัสภาพและการรับไฟล์ผ่าน API ให้กำหนดในแผนพัฒนา

## ตัวอย่างตรวจรับ

- นำเข้าข้อมูลที่ตรวจแล้วได้ 90 รายการตามลำดับ ภาพเริ่มต้นว่าง และค้นด้วย `TERRA COTTA` เจอทั้งดินแดงกับดินแดงเคลือบใสแยกกัน
- ขาวฟ้า เขียวศิลาดล และศิลาดลแสดงหมายเหตุตามต้นทาง รายการอื่นแสดงได้ตามปกติแม้ไม่มีหมายเหตุ
- บันทึกชื่อโดยไม่แนบภาพได้ เพิ่มภาพภายหลัง เปลี่ยนภาพ และลบเฉพาะภาพได้ ไฟล์เสียหรือใหญ่เกินกำหนดไม่เปลี่ยนภาพเดิม
- ผู้ดูชาร์ตเปิดชื่อและภาพได้ ผู้จัดการเพิ่ม ลบ แก้ไขได้ และการบันทึกข้อมูลตั้งต้นซ้ำไม่เพิ่มรายการ
- ซ้อมสำรองและกู้คืนฐาน Docker แยกด้วยข้อมูลทดสอบที่มีทั้งรายการไม่มีภาพและรายการมีภาพ ตรวจว่าชื่อ ลำดับ หมายเหตุ และข้อมูลภาพตรงกัน
