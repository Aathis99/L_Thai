# ระยะแรก: พนักงานและการเข้าถึงระบบ

ผู้ใช้สั่งให้เริ่มส่วนนี้ก่อน โดยพักการสัมภาษณ์กระบวนการผลิตไว้ ข้อเลือกทางเทคนิคและสิทธิ์เริ่มต้นด้านล่างเป็นข้อเสนอของผู้พัฒนา ปรับได้เมื่อทดลองใช้งาน

## เป้าหมาย

เข้าสู่ระบบได้จริง จัดการพนักงาน ตำแหน่ง บัญชี และสิทธิ์ได้ ข้อมูลอยู่ถาวรบนเครื่อง ไม่มีพนักงานตัวอย่างปะปนกับข้อมูลจริง

## แนวทาง

เลือกเว็บแอปภาษาไทยรันภายในเครื่อง เพื่อเปิดจากเบราว์เซอร์และวางพื้นฐานสำหรับหลายผู้ใช้ภายหลัง ใช้ Node.js 26 และ SQLite ในไฟล์ ไม่ต้องติดตั้งฐานข้อมูลแยก การเปิดผ่านเครือข่ายโรงงาน/HTTPS/สำรองอัตโนมัติเป็นงานระยะติดตั้งจริงภายหลัง ทางเลือกไฟล์ Excel เดิมยังต้องกรอกซ้ำ ส่วนระบบ ERP ครบชุดยังขาดข้อมูลหน้างาน

## ขอบเขต

- ตั้งผู้ดูแลคนแรกครั้งเดียว ไม่มีรหัสผ่านเริ่มต้น
- Login/logout เปลี่ยนรหัสผ่านตนเอง เซสชัน HttpOnly อายุ 8 ชั่วโมง รหัสผ่าน scrypt
- พนักงาน: รหัส ชื่อ แผนก ตำแหน่ง โทรศัพท์ สถานะ เพิ่ม/แก้ไข/ค้นหา/กรอง/ลบแบบเก็บประวัติ
- ตำแหน่งงานแยกจากบทบาทสิทธิ์ ลบตำแหน่งที่มีพนักงานอ้างอิงไม่ได้
- บัญชี login แยกจากพนักงาน เชื่อมกันได้ แต่พนักงานไม่จำเป็นต้องมีบัญชี
- บทบาทเริ่มต้น ผู้ดูแล/ผู้บันทึก/ดูข้อมูล ปรับสิทธิ์หรือเพิ่มบทบาทได้ ผู้ดูแลระบบเป็นบทบาทสงวนและห้ามปิดผู้ดูแลคนสุดท้าย
- ตรวจสิทธิ์ที่ API ทุกครั้ง ปิดบัญชี เปลี่ยนรหัสผ่าน หรือเปลี่ยนสิทธิ์มีผลกับ session ที่มีอยู่
- บันทึกการเปลี่ยนข้อมูลโดยไม่เก็บรหัสผ่านลงประวัติ
- รอ Excel จริงก่อนทำ mapping และนำเข้าข้อมูล

## ยังไม่ทำ

ออเดอร์ เบิกดิน ยอดคงเหลือ ล็อตผลิต เส้นทางผลิต ทาสี รายงานค่าแรง และการ deploy ออนไลน์

## การตรวจสอบ

Integration tests ใช้ HTTP และฐานข้อมูลชั่วคราวจริง: ตั้งระบบซ้ำไม่ได้, login ผิด/ถูก, logout, CRUD, สิทธิ์ดูอย่างเดียว, การเปลี่ยนสิทธิ์ทันที, ผู้ดูแลคนสุดท้าย, validation, CSRF และข้อมูลคงอยู่หลังเปิดใหม่ ตรวจหน้าจอผ่านเบราว์เซอร์ด้วยฐานข้อมูลทดสอบแยกจากของผู้ใช้
